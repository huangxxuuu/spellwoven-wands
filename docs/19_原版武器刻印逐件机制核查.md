# 原版武器刻印逐件核查 · v0.23.6

**84 张武器刻印中，83 张能在武器刻印台制作，另一张是猪人定向掉落的道具招牌。** 长矛、玻璃刀和普通斧头对应的是另写的三张招式。下表把它们也纳入，共核查 87 张已有卡。火魔杖、冰魔杖等没有同名刻印，另列在文末。

## 核查口径

- 依据本机《饥荒联机版》构建 **761239** 的 `data/databundles/scripts.zip`，对照 Mod **6c0801d**。下表的原版脚本名默认在包内 `scripts/prefabs/` 下，带 `components/`、`brains/` 或 `stategraphs/` 的从 `scripts/` 起算，后缀均为 `.lua`。数值来自该构建的 `scripts/tuning.lua`。
- 排除直接挥击、砍树、铲掘、采矿和锤建筑。保留需要不同操作或改变战果的机制，例如翻土造种植堆、移除整块地皮、采收枝草、击落物品、吸血、招架、装备加速和范围施法。通用的交易、烧作燃料、制作其他物品等不逐项展开。
- “已有”指当前代码存在对应路径。84 张刻印在释放点生成攻击效果，命中时可以调用**临时原物**的 `weapon:OnAttack`。这种路径能传入施法者和受击者，但不会让玩家真的装备原物、操作其容器、发动右键技能或把原物的状态保留到下次施法。本表是代码核对，未逐项进行实机验证。[刻印目录](../mod/scripts/nw/weapon_catalog.lua) · [卡牌定义](../mod/scripts/nw/arsenal.lua) · [命中实现](../mod/scripts/nw/melee.lua) · [工具动作实现](../mod/scripts/nw/weapon_work.lua)

## 最容易误判的四件

| 原物 | 核查结果 |
| --- | --- |
| 鱼食 | 原版判定的是**投掷落点是否为海洋**，不需要先命中一条鱼。落海后撒饵并尝试生成鱼群，落陆还原为物品。现有卡没有走投掷落点逻辑。 |
| 懒人魔杖 | 橙杖移动的是**使用者**，需要合法落点。紫色传送魔杖可以把目标送往传送焦点或随机位置，是另一件物品。 |
| 暗影收割者 | 玩家说的范围收草和树枝已经有部分实现。原版从人物面前收割，卡则从法术释放点收割，搭在碰撞载体后可以把收获中心送到远处。 |
| 国王魔杖 | 现有目录里真正能换宝石施展多种魔法的是这一根；卡目前没有宝石状态。独立的火、冰、唤星和唤月魔杖则要分别看待。 |
