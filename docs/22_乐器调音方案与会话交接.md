## 2. 调音操作方案

| 建议 ID（美术清单已使用） | 卡名 | 音高偏移 |
| --- | --- | --- |
| `pitch_octave_up` | 升八度 | +12 半音 |
| `pitch_octave_down` | 降八度 | −12 半音 |
| `pitch_semitone_up` | 升半音 | +1 半音 |
| `pitch_semitone_down` | 降半音 | −1 半音 |

用户认可的总体方向为四张独立调音修饰；以下是交接给实现阶段的规则方案，尚未编写这四张卡的功能：

1. 同组所有调音偏移相加，正负抵消，组内排列顺序不影响最终偏移。例：A4 + 升八度 + 降半音 = G#5。
2. 沿用当前编译器的施法组作用域。同组多重施法的所有乐器音一起移调；下一组重新计算；碰撞、定时等载荷拥有独立修饰组，默认不继承父组调音。
3. 音高只影响声音，不影响声波速度、寿命、伤害、回理智等效果，也不改变卡牌 ID。陶笛 C 移调后仍具备回声应答；B 升成 C 不会因此获得该玩法能力。
4. 卡面保留基础音；未来组合预览可显示“基础 A4 → 实际 G#5”，无需为每种移调结果再画一张基础卡。此预览功能仍是待实施建议。
5. 音源接入接口按“乐器类型 + 最终音高”组织。音域和越界处理等用户提供音源后再定，不沿用静默截成其他边界音的做法。法力、稀有度、获取配方等尚未确定。
