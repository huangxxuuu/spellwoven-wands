## 确定性的属性生成 v3（0.25.1）

不再使用属性点或总预算。先确定稀有度与类型，再分别按离散截断正态权重抽取属性。候选值权重为 `exp(-0.5*((x-中心)/标准差)^2)`，只对合法候选归一化，不把越界值压到端点。随机流使用 Park–Miller；同种子、阶级、类型和生成版本可复现。

全局兼容边界包含旧存档和固定入门杖；新随机杖使用下面更窄的分阶范围。旧杖不重抽，继续保存原有数值、卡牌、名字和外观。

| 属性 | 全局下限 | 全局上限 | 新生成精度 |
|---|---:|---:|---:|
| 容量 | 2 | 12 | 1 |
| 法力上限 | 24 | 1200 | 5 |
| 回蓝 / 秒 | 2 | 320 | 1 |
| 施放间隔 / 秒 | 0.08 | 2.4 | 0.01 |
| 充能 / 秒 | 0.1 | 6 | 0.01 |
| 散射 / 度 | 0 | 15 | 0.5 |
| 基础同发 | 1 | 6 | 1 |

SAN 转化率固定 20；乱序为布尔值。随机生成的基础施放间隔仍不低于 0.20 秒，这是生成分布限制；卡牌修正后的施放间隔和充能时间均可降到零，实际速度仍受原版攻击动作、角色战斗冷却和法术专属冷却约束。

每格格式为 **下限～上限；中心 / 标准差**。中心是类型修正前的分布峰值，不是截断后样本的精确均值。

| 属性 | 普通 | 精良 | 稀有 | 史诗 |
|---|---|---|---|---|
| 容量 | 3～7；5 / 1 | 4～9；6 / 1.15 | 6～11；8 / 1.15 | 8～12；10 / 1 |
| 法力上限 | 80～240；140 / 35 | 120～450；240 / 65 | 200～800；420 / 120 | 320～1200；700 / 180 |
| 回蓝 / 秒 | 12～45；25 / 7 | 20～90；45 / 14 | 35～180；85 / 28 | 60～320；150 / 45 |
| 施放间隔 / 秒 | 0.5～1.4；0.85 / 0.18 | 0.32～1.05；0.6 / 0.14 | 0.2～0.75；0.4 / 0.1 | 0.2～0.55；0.28 / 0.07 |
| 充能 / 秒 | 0.7～2.6；1.5 / 0.35 | 0.4～1.9；1.05 / 0.28 | 0.22～1.3；0.65 / 0.2 | 0.1～0.9；0.4 / 0.14 |
| 散射 / 度 | 1～12；6 / 2.5 | 0～10；4 / 2 | 0～8；2.5 / 1.5 | 0～6；1.5 / 1.2 |

类型仅移动中心，不突破该阶上下限。下面偏移以该阶原始标准差为单位；施放、充能、散射的负偏移表示改善。萌芽保持中心，标准差缩为 0.75 倍；其他类型保持标准差。

| 类型 | 中心偏移 | 同发 1～6 的抽取权重 | 乱序 |
|---|---|---|---|
| 萌芽 | 无；分布更集中 | 55 / 22 / 12 / 6 / 3 / 2 | 固定非乱序 |
| 速射 | 容量 -0.6σ、法力上限 -0.6σ、回蓝 / 秒 +0.7σ、施放间隔 / 秒 -1σ、充能 / 秒 -0.6σ | 70 / 18 / 7 / 3 / 1.5 / 0.5 | 随阶级 |
| 蓄能 | 法力上限 +1.25σ、回蓝 / 秒 -0.6σ、充能 / 秒 +0.7σ | 40 / 25 / 16 / 10 / 6 / 3 | 随阶级 |
| 复苏 | 法力上限 -0.7σ、回蓝 / 秒 +1.3σ、施放间隔 / 秒 +0.35σ | 60 / 22 / 10 / 5 / 2 / 1 | 随阶级 |
| 编织 | 容量 +1.3σ、施放间隔 / 秒 +0.6σ、充能 / 秒 +0.35σ | 65 / 18 / 9 / 5 / 2 / 1 | 固定非乱序 |
| 混沌 | 法力上限 +0.6σ、施放间隔 / 秒 -0.5σ、散射 / 度 +1σ | 10 / 20 / 25 / 22 / 15 / 8 | 固定乱序 |

同发抽取先排除超过容量的候选，再归一化其余权重；单发作为独立风格保留，不视为低阶惩罚。速射各阶的回蓝下限足以覆盖最快基础间隔下一发火花的消耗，复杂卡组仍由玩家搭配。

随阶级的乱序概率为普通 50%、精良 35%、稀有 20%、史诗 10%。普通与精良没有固有法术；稀有 10%、史诗 25% 获得加速或精准，等概率选择，不扣除其他属性。无主题来源时六种类型等概率；Boss 来源仍可偏向特定类型。

入门杖固定两格、非乱序、同发 1、法力 120、回蓝 18、施放 0.65 秒、充能 1.4 秒、散射 6°，内置火花弹。制作随机杖为空槽，Boss 掉落继续使用原来源卡组规则。外观根据最终容量、乱序、同发等属性生成。

本表由 `tools/export_wand_generation.py` 从实际配置生成。每阶 12,000 个等比例类型样本；“极端”统计定义为六项中任一项偏离自身类型中心超过两倍标准差，类型预设弱项不另视为极端。
