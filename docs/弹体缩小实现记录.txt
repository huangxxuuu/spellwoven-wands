弹体缩小实现记录
日期：2026-11-12；状态：本地开发版完成，未提升版本、未提交或发布。

法术：shrink_shot / 弹体缩小 / Shrink Shot，稀有修饰卡，范围标签。
奥术台配方：空白卡×1、紫宝石×1、月岩×3。
法力16、施法间隔修正+0.05秒、回充修正0。
定义顺序在dark之后追加；新code=225，旧code不变，193退休编号保留。
当前公共卡188张，兼容卡在内共224张。组合美术189张包含历史音符，暗影浓雾仍走既有源图回退，不能把组合美术数量当成公共卡数量。

效果：每张缩小×0.4，同组相乘，最终最低×0.1；巨化仍按每张2.5相加，再乘缩小。混用与排列顺序无关；一巨化一缩小恢复原尺寸。独立载荷使用自己的修饰，伤害、速度、主体寿命不变。
覆盖碰撞、近战、静态场、哨株、虫群、星体的光照/温度/理智/传播范围，以及原版哑铃、龙卷风和三叉戟的实际范围。
星体缩小需要抵消原版范围外残留的加热/冷却；光照按原版脉冲结果缩放，零值初始同步不导致黑灯。
原版哑铃回调仅临时代理当前Lua函数的TheSim查询环境，异常恢复，不修改全局TheSim/TUNING。
龙卷风保留原版动作和攻击时序；三叉戟同步缩小船漏水环、海浪与农作抚育范围。

美术：采用本地OpenAI API gpt-image-2.6-sunburst，实际Prompt、透明原图、用量记录、白灰底及128/64/32像素预览：assets_src/spell_card_subjects/v10_shrink_shot/。
采用与巨化相同的青蓝弹体、金色箭头和六边形卡框；弹体缩小，三支箭头向内。
已编译库存图集、地面独立卡面分页及牌堆共享资源；实际编译后的对比：test_reports/shrink_shot_compiled.png。
本地中英文资料站及docs/07_法术说明与参数.md已更新。没有更新线上资料站或工坊。
