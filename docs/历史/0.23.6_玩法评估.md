# 《织法之杖》玩法评估 · v0.23.6

**下一版优先补上从「会发射」到「会配杖」的那一步。** 入门杖自带一张火花弹，玩家第一次拿到就能试射。更有意思的发现是，换一张卡可以改变下一张卡的行为，甚至把近战送到远处。这个发现值得提前到玩家做出第一根杖的时候。

本评估依据 `main` 的 `6c0801d`。上一轮 34 组自动测试和独立服务器测试已通过。以下是对现有机制的判断，首次上手耗时、真实联机手感、界面缩放和长局强度仍待玩家实测。

## 从开荒到长期存档

| 方面 | 玩家会经历什么 | 值得丰富或验证的地方 |
| --- | --- | --- |
| 上手难度 | 按制作路线起步，先要炼金引擎和两颗紫宝石建奥术台。入门杖只有两格且固定顺序，能排除乱序干扰；但玩家得另做或拾到第二张卡，才能体验一次编排。 | 保留自带火花弹的入门杖。在其配方或奥术台说明里给出一条能照着摆的两格示例，让玩家知道第二张卡值得去找。 |
| 界面与操作 | 悬停能看实际槽序、属性和卡面；蓝条、冷却环和换卡图标也都有悬停提示。武器刻印台能做卡，回到奥术台才能装卡；玩家拿着新卡站在刻印台前，操作看起来合理却不能完成。 | 给刻印台加一句「带回奥术台装杖」。HUD 当前把法力不足和没有有效法术合并为同一条提示，最好分别告诉玩家应该等回蓝还是回台调整。分类标题在常用缩放下是否好读，留到晚上看实际画面。 |
| 可玩度 | 同一招「斧子旋转」直接施放时扫身边，接在「魔法箭·碰撞」后则在箭的接触点旋斩。玩家得重新考虑站位、瞄准和选敌。乱序、基础同发和法力回复又影响同一套卡适合哪根杖。 | 把这类能看见差异的对照做成少量范例。先让玩家预测会在哪里出招，再让他去掉前一张卡试一次，胜过抄一根十二格成品杖。 |
| 内容丰富度 | 201 张卡中有 164 张可制作。刻印台的 86 张含 3 张原创招式和 83 张可制作的原版武器刻印。许多刻印共享突刺或扇形攻击，差别在原武器伤害、工作动作或个别特效。采矿、耕地、友方治疗以及两套音符，已经给非战斗玩家留下了位置。 | 近期可用现有卡组织三种具体玩法，例如矿区作业、洞穴照明、守家治疗。若继续扩卡，优先选能改变玩家行动或队伍分工的效果；再添相近伤害的刻印，带来的新体验较小。 |
| 获取与重玩 | 制作能让玩家规划大部分卡；材料关联掉卡、指定生物掉卡和首领携卡杖则会打乱原计划。同类杖还要比较施放间隔、充能和回蓝。多余卡和杖能回收粉尘，分解杖时会退还已装卡。 | 已知卡反查来源很有价值，尤其是没有配方的 37 张。先给它们标出「去打谁」「从哪类掉落杖上拆」，再根据长档反馈决定是否需要保底。极低概率随机掉落难以作为玩家能主动追求的目标。 |
| 平衡与成长 | 一根杖的属性有预算约束，但多重抽取、复制、重复触发和穿透会共同影响实战收益。施法还会消耗理智，理智为零仍可施法，不同角色和战斗时长承担的代价可能不同。 | 选同一角色和目标，把原版常用武器、同进度制作杖、成型触发杖各试一轮。分别记首击伤害、30 秒有效输出、回蓝空窗与理智消耗，再判断是否要调哪一张卡。仅凭单次齐射很难评价持续强度。 |
| 多人与长期维护 | 活力环能治疗队友和随从，工具刻印支持共同采集；这些给偏辅助的玩家提供了分工。世界已有弹体、晶体和雷云等上限选项，默认可不限。专服自检覆盖加载与规则，但加入者能否看清治疗落点、顺畅换卡，需要两端观察。 | 做一次两人守营地的完整遭遇，一人用输出杖，一人带活力环。交换角色后再试，记录谁看得见落点、是否能跟上队友走位、密集施法期间是否卡顿。 |

## 建议的开发顺序

1. **先用一次新手试玩决定提示写在哪里。** 让未读图鉴的玩家拿到入门杖和一张「伤害强化」，请他在奥术台装成「伤害强化 → 火花弹」，再离台试射。记录第一次停住的地方，以及他是否知道为什么要这样排序。只有拿卡、找台或摆槽其中一步真的费解，才在对应界面补一句。
2. **把现成内容变成玩家能主动追的目标。** 在图鉴给触发、工作、辅助各留一个可复现的组合，每个都列所需卡、最低槽数和一条现实的获取路线。用「能否凭线索凑出第二套用途不同的杖」判断获取体验。
3. **等战斗和联机数据再动数值。** 优先对照首领单体、普通群怪和两人协作三种情况。若差距集中在某一组合，再回头区分是落点更安全、复制收益过高，还是另一根杖经常空蓝。这样能保留配出好杖的奖励。
