# 美术风格与游戏资源规格

适用版本：0.4.1-prototype。生成使用内置 imagegen，未使用外部图片 API 或额外插件。原始图已复制到项目；安装包只包含编译后的游戏资源。本次只调整弹体的运行时显示尺度，没有重新生成图像。

## 统一风格与提示词

统一采用歪斜手绘墨线、暗色轮廓、少量排线、低饱和矿物色和象牙白高光。每个元素必须有可辨认的主体轮廓，不能只靠换色。火花为金色彗星，魔箭为青色骨箭，重弹为紫色裂壳能量球；双重与三重分别显示两枝、三枝施法分叉。

原始提示词共有同一个风格段，后接单独的主体描述：

> Single production inventory spell sprite, square composition, genuine transparent alpha. Original gothic survival storybook illustration: bold crooked near-black ink contours, dry-brush hatching, muted mineral colors and ivory highlights, one clear luminous accent, deliberately handmade imperfect silhouette. Very readable at 64x64. No background, frame, text, letters, numbers or watermarks. Subject: …

库存专用重绘更强调小尺寸可读性：

> Create a dedicated SMALL INVENTORY ICON designed on a conceptual 64x64 pixel grid, delivered as a larger clean image for final downsampling. Thick near-black imperfect contour, flat color regions, ONLY 3–4 tones, minimal large highlights, no fine texture or micro-details. Chunky shapes readable at 32 pixels too. Genuine transparent background. Subject: …

完整的逐图提示词及生成结果来源见 [generation_log.json](../assets_src/art_v1/generation_log.json)。共 35 张原始图及 4 张库存专用重绘。连锁闪电、生命汲取、正弦、精准使用重绘版本；其他图经过 64 像素检查后保留。并非把所有复杂原图无条件缩小，也不要求把所有图都重新生成。

## 游戏尺寸

| 用途 | 导出 PNG 像素 | 动画中的尺寸／界面显示 |
| --- | --- | --- |
| 25 个法术图标、1 个法杖图标 | 每个 64×64；512×256 图集 | 库存由游戏控件显示；法术槽和选择按钮显示 28×28 |
| 水晶头、分叉头 | 各 80×80 | 40×40 动画单位 |
| 短／中／长杖身 | 36×104、36×160、36×224 | 18×52、18×80、18×112 动画单位 |
| 紫晶尾、琥珀尾 | 各 48×56 | 24×28 动画单位 |
| 奥术台 | 256×256 | 144×144 动画单位 |
| 训练靶 | 128×192 | 80×120 动画单位 |
| 地面法术卡、弹体 | 使用对应 64×64 法术图 | 基础 32×32 动画单位；弹体缩放：火花／魔箭 1.6，重弹 2.0，散弹 1.4；地面卡片不变 |

动画单位不是固定屏幕像素，实际观感受镜头距离和游戏缩放影响。64×64 是本 Mod 当前库存资源规格，不是引擎对所有图片的唯一要求。

生成大图只作源素材。构建会清理 alpha≤8 的几乎不可见散点，再按主体裁切：这可避免远离主体的透明噪点把细长杖身压缩成一根像素线。库存图保持长宽比、至少四像素留白；模块部件归一到约定的接头尺寸。不会把大图原样塞入库存。原图保持不变。

## 三段拼装

七个部件保存为独立 build symbol，运行时用 OverrideSymbol 和三种长度动画拼装。两种头×三种身长×两种尾共 12 种组合，没有预烘焙成十二根整杖贴图。水晶头对应非乱序，分叉头对应乱序；格子越多杖身越长；高回蓝使用琥珀尾。

当前仍未把“多发数量”独立编码为更多杖头尖端，也未实现组合式库存外观：法杖库存共用一个完整杖图标。这是原型的既有限制，不能把这轮美术替换视为完整外观规格验收。

部件本身为静态单帧符号，手持跟随人物 swap_object 动画；没有独立挥动或发光动画。奥术台、训练靶和法术弹体均已替换几何占位资源。透明 anchor 只用于隐藏原装备符号，不是可见物品。

## 文件与重建

- `assets_src/art_v1/originals/`：35 张原始素材。
- `assets_src/art_v1/icon_redraws/`：4 张库存专用重绘。
- `assets_src/art_v1/runtime/`：游戏尺寸 PNG、动画 XML、图集源图。
- `mod/anim/nw_parts.zip`、`nw_objects.zip`：官方工具生成的动画资源。
- `mod/images/inventoryimages/nw_icons.tex`、`nw_icons.xml`：BC3、预乘 alpha 库存图集。
- [64 像素库存检查图](../assets_src/art_v1/inventory_64_review.png)、[三段拼装检查图](../assets_src/art_v1/assembly_review.png)。

```powershell
.venv/Scripts/python.exe tools/build_assets.py
.venv/Scripts/python.exe tools/check_art_assets.py
```

检查包括独立图标数量、透明通道、图集坐标和动画二进制头。客户端还需验证实际压缩纹理的颜色边缘、图标清晰度、手持位置和各镜头距离；离线专服无法证明这些视觉效果。
