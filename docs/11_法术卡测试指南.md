# 法术卡、外观与施法实机测试

当前版本请优先使用文末的[成套测试箱与验收清单](#当前验收清单与成套测试箱)。下文保留了历次专项记录；与旧版本文字冲突时，以当前清单和游戏内卡牌参数为准。

在世界的服务器模组配置中开启「织法之杖 · 开发版」的「开发者选项」，保存并重启世界。此项默认关闭，关闭时包括 `nw_help` 在内的开发者命令均未注册。开启后先用远程控制台执行 `nw_help()` 查看命令和用法。建议用有一片空地的测试世界。按 `~` 打开控制台，房主或管理员选“远程”，在自己的角色旁执行以下命令。测试卡通过控制台领取，生存模式可制作 144 种卡，其余按战利品规则获取。配方和击杀复测见[获取系统实机验收](09_获取系统实机验收.md)。

| 命令 | 结果 |
| --- | --- |
| `nw_spellkit()` | 按类摆放的箱子，内有全部 182 张设计卡各一张；另有奥术台和一根 12 格空测试杖（600 蓝，回蓝 80/秒，非乱序） |
| `nw_card("arrow_hit")` | 单领指定卡。可重复调用以配多张同名卡。所有 ID 见[参数表](07_法术说明与参数.md) |
| `nw_range()` | 在面前可通行的位置摆放一列敌对判定的测试靶、侧靶和一只初始半血的友方随从靶，检查靶子可看当前生命 |
| `nw_combo("remote")` | 领取已装“魔法箭·碰撞 → 玻璃刀砍”的测试杖 |
| `nw_combo("imprint_timer","heavy","slash")` | 按参数顺序装一根自定义杖，最多 12 张。无参数时给空杖 |

先装备测试杖，靠近奥术台，从物品栏拿起法术卡，点击物品栏上方的法术槽进行替换。单击右键施法一次，按住右键在站定时连续施法。装卡后等整杖充能结束，每次领取组合杖后需要亲自装备新杖。

## 零施法间隔与零充能

开启开发者选项后，在远程控制台执行以下整行命令，领取基础施法间隔和整杖充能均为 0 的火花测试杖（600 蓝，回蓝 80/秒），然后亲自装备：

```lua
local w=nw_combo("spark");local c=w.components.nw_wand;c.data.stats.cast_delay=0;c.data.stats.recharge=0;c.data.config_revision=c.data.config_revision+1;c:Sync()
```

按住右键应按原版攻击动作连续施放，无额外法杖等待；每次动作只结算一次。保存重进后，两项基础时间仍应为 0。也可用 `nw_combo("mana_reduce","recharge_down","recharge_down","recharge_down","recharge_down","spark")` 测试卡牌修正将两项有效等待降到 0；此组合的面板基础时间仍为 0.45 / 0.60 秒。唤星、唤月等法术的专属冷却仍生效，包括作为触发载荷时。

## 0.23.1 地面法术卡与牌堆

1. 远程控制台执行 `nw_card("whirl")`，丢到地上，检查完整斧头、金色旋转轨迹和四边。鼠标移上再移开，两次都应看到同一张卡。
2. 分别用 `nw_card("frost")` 和 `nw_card("target_friendly")` 领取冰霜弹和友方目标。用鼠标拿起冰霜弹，右键地上的斧子旋转，再把友方目标卡加入。三张牌组成的牌堆应保持斧头卡的大小、透视和顶面图案，底部能看到叠层。
3. 打开牌堆，取走第一格的斧子。即便第一格留空，堆顶也应切换为第二格的冰霜弹。存档重进后再取走冰霜弹，最后一张应以单张友方目标卡落地。

## 0.22.4 粉尘鼠标命中与建筑接地

完全退出并重启客户端和世界后，在测试世界用远程控制台执行 `c_spawn("nw_dust")`。空手把鼠标从袋外缓慢划过袋口、袋身、右下边缘。袋身中央应出现“捡起”，直接左键应走过去收进背包。换用分解炉产生的一叠粉尘复测，并旋转一次镜头。此前只能在袋子左上方点中的情况应消失。

三座建筑复用了炼金引擎脚下的断续墨线阴影。在白天地皮和浅色石路分别检查：地皮应能从墨线间露出，脚沿有少量翻起的土块；炉芯启动、闪光和熄灭时，地面接触位置应固定。

## 0.22.3 刻印台入口和可选数量限制

- 搜索“武器刻印台”，或查看原版“制作站”和“魔法”筛选。首次在炼金引擎旁用木板 ×2、石砖 ×2、紫宝石 ×1 制作原型。可以取消放置预览，走远后再选配方，在可建造的空地部署。
- 默认世界设置下，用 `nw_combo("repeat_3","repeat_3","scatter")` 打出 27 枚弹丸。将“单次施法攻击实体上限”设为 12 并重启世界后，同一组合应被拒绝。全局玩家子弹数量开关如果手动开启，会另行检查并发额度。
- 用 `nw_combo("repeat_3","spore_sentry")` 在空地一次放三株。默认三株均能留下；将“每位玩家的荚刺哨株上限”设为 2 后，第三株会替换第一株。哨株本身的寿命与三枚荚刺照常结算。
- 晶体、雷云和照明残光各有并存数量设置，雷云还可设分片上限。全部默认不限。用 `nw_combo("repeat_3","storm_cloud")` 验证三朵雷云能同时存在。空地上重复施放照明弹可观察残光达到设置值后才替换最早的一处。

## 0.22.2 海岸、哨株与地面拾取

1. 用 `nw_combo("arrow")` 装备魔法箭杖，在岸边右键空海面，检查施法提示和飞行轨迹；上船后分别向岸上和外海射击。墙体仍按普通命中、穿墙或反弹修正结算。
2. 用 `nw_combo("spore_sentry")` 在猎狗旁施法。哨株是 60 生命的临时随从，怪物可选中、攻击和击倒它。观察击倒后是否停射，已有仇恨的怪物依原版 AI 决定是否换目标。
3. 世界 Mod 设置「每位玩家的晶体数量上限」默认不限，可选 30、60、120。用 `nw_combo("repeat_4","sleep_crystal")` 连续施放，在早期晶体自然到期之前累计超过 30 枚。若开启 30 枚上限，第 31 枚替换最早的一枚，两种晶体合计；`nw_combo("detonate")` 可引爆范围内本人的晶体。
4. 在草地或石地并排放奥术台、刻印台和分解炉，检查脚下阴影、泥痕及放置预览。用 `c_spawn("nw_dust")` 在空地放粉尘，仅用鼠标依次指向袋身和底边，检查悬停、左键拾取；再测试分解炉实际产出的粉尘堆。

## 0.19.0 近战、工作、目标与乐谱

近战攻击和工作均从杖头或载体的实际释放点发生。原版生存模式的手持近战武器、能近战的工具和节庆手持道具均有对应卡。原来的长矛、玻璃刀和斧子沿用原卡。制作使用两个对应武器、一张空白卡和一份魔法材料；道具招牌从猪人掉落。物品原有的装备技能、耐久和人物专属技能不属于卡牌攻击。

普通工具在半径 1 内工作，多用斧镐、暗影槌和暗影收割者半径为 2。每个目标独立累积原版工作量的 75%。普通斧命中四次等于三次原版工作。月光玻璃斧的基准效率为 2.5，每次贡献 1.875。支持采矿、砍伐、铲掘、锤击、镰刀收割，相关工具也可捕捉、耕地和起草皮。作物和矿物可以触发命中载荷，实际工作由带对应能力的工具卡完成。

目标修饰在同组取并集，仅对当前分组生效；载荷不继承母弹的选择，需要在载荷分组另放选择卡。建筑和植物矿物可被弹体接触，没有生命值的目标不会因为普通伤害被摧毁。其他玩家的直接攻击需要世界开启 PvP。单独装「选取自身」会在施法者位置释放。将「选取其他玩家」和「选取自身」装进同组即可同时选择两者。0.19.0 存档中的「选取玩家（含自身）」会在原槽位转为「选取其他玩家」。

| 命令 | 效果 |
| --- | --- |
| `nw_combo("target_nature","edge_multitool_axe_pickaxe")` | 在释放点周围砍树和挖矿。 |
| `nw_combo("target_building","arrow_hit","edge_hammer")` | 远程命中建筑，由载荷在落点锤击。 |
| `nw_combo("target_self","spark")` | 离开自身碰撞范围后才允许命中本人；搭配往返弹道验证回程。 |
| `nw_combo("double","note_a","ocarina_a2")` | 同一次施法奏出相隔一个八度的两个 A。 |
| 对比 `nw_combo("kantele_dsharp")`、`nw_combo("speed_up","kantele_dsharp")`、`nw_combo("speed_down","kantele_dsharp")` | 三者音高均为 C4；加速、减速不再改变音符音高。内部 ID 沿用旧名称以兼容存档。 |
| `nw_combo("pitch_octave_up","pitch_semitone_down","note_a")` | A4 升八度后降半音，得到 G#5；交换两张调音卡顺序结果相同。 |
| `nw_combo("pitch_octave_up","pitch_octave_down","note_a")` | 升降抵消，仍为 A4。 |
| `nw_combo("double","note_a","pitch_semitone_up","note_c")` | 同组两个音均升半音，调音卡对前面已抽到的音也生效。 |
| `nw_combo("pitch_octave_up","arrow_hit","note_a")` | 载荷不继承父组调音，命中载荷仍奏 A4。把升八度放到载体后面则载荷奏 A5。 |
| `nw_combo("pitch_octave_up","ocarina_a2")` | 奏出陶笛 A6，新音源已覆盖此音。 |
| `nw_combo("pitch_octave_down","pitch_semitone_down","note_a")` | 陶笛下界 G#3 正常发声；再放一张降半音得到 G3，应静音但声波正常。 |
| `nw_combo("pitch_octave_up","pitch_semitone_up","ocarina_a2")` | 陶笛上界 A#6 正常发声；再放一张升半音得到 B6，应静音但声波正常。 |
| `nw_combo("pitch_octave_down","pitch_semitone_down","kantele_a")` | 弦琴下界 G#2 正常发声，尾音完整；再降半音静音，理智回复仍生效。 |
| `nw_combo("pitch_octave_up","pitch_semitone_up","kantele_g")` | 弦琴上界 G#5 正常发声；再升半音静音，理智回复仍生效。 |
| 两名玩家在附近分别演奏并逐渐远离 | 两人都能听到两种不同音色；随距离衰减。连续演奏和同组和弦不应因视觉消失而截断尾音。 |
| 单次施放陶笛 A4 后停止，再单次施放弦琴 C4 后停止 | 各自只起音一次并自然衰减；陶笛约 1.15 秒结束，弦琴尾音较长但不得重新起音。连续演奏多个不同音后停手，也不得残留反复起音或循环音序。 |

已使用作者提供的独立乐器音色：陶笛 G#3–A#6（39 音），弦琴 G#2–G#5（37 音），范围内包含全部半音。卡牌悬停显示基础音与可调音域。四张独立调音卡分别偏移 ±12、±1 半音，同组相加，跨组和载荷隔离；超出范围静音，但声波、标记和理智恢复照常。加速、减速只保留移动及寿命效果。所有弦琴音共享原有的理智恢复间隔，陶笛 C 移调后仍可触发应答，B 升为 C 不会获得应答能力。四张调音卡均在奥术台“音符法术”中制作，耗蓝1，无额外施法延迟。ID 与完整音高表见[法术参数表](07_法术说明与参数.md)。

## 0.14.0 法杖栏与本机拖动位置

重启客户端和服务器。在远程控制台执行 `nw_hudkit()`，领取 2、7、12 格试杖（法力上限分别 120、260、600）、一张火焰卡和身旁一座奥术台，依次装备测试。

1. **伸缩边框**：外框包住法术格及顶部图标，2～12 格时保持格子大小与边框粗细。不同法杖的蓝条外框长度相同，填充比例表示剩余法力，不常驻显示数字。
2. **状态**：远离奥术台显示禁止图标，靠近显示羽毛笔。施法减少蓝色填充，随后自动恢复；冷却圆环顺时针填满，能施法时星形图标亮起。鼠标停在图标或蓝条上可读具体说明。
3. **明显冷却与缺蓝**：装备试杖后执行 `nw_saveprobe()`，人为设置 30 秒冷却，观察圆环从头推进至就绪。冷却结束后执行 `nw_manaprobe()` 清空蓝条，观察缺蓝变灰并随回蓝恢复就绪。空杖无有效法术时也应显示灰色。
4. **移动窗口**：在边框、空白或顶部图标处按住右键约 0.15 秒，再移动鼠标，松开完成。拖动应跟随鼠标且不施法；在法术格上按住右键不拖动窗口。短按右键不移动窗口；原有左键换卡和拖卡继续有效。
5. **位置保存**：移到另一处后切换法杖、卸下再装备、保存退出，再完全关闭游戏并重启。窗口应回到上次位置；该设置只保存在本机，不影响其他玩家。拖到屏幕边缘后换成 12 格杖，整条应保持在屏幕内。
6. **缩放和中断**：试不同 HUD 缩放、窗口分辨率、整合背包。拖动中按 Esc、卸下法杖，确认没有残留拖动或自动施法。非常窄的屏幕上，整条会必要地等比缩小以保持可见。
7. **联机客户端**：若有加入者，可各自拖到不同位置，确认互不影响；客户端显示的蓝条和冷却应随服务器实际消耗变化。

保存使用客户端持久化键 `nw_weave_hud_position_v1`，存屏幕归一化位置，松开时写入；配置损坏时自动回到物品栏上方。自动检查覆盖 2～12 格布局、分辨率边界、输入互斥、异步保存与重启读取；独立专服不验证鼠标操作及画面，以上项目需要图形客户端实测。

## 0.13.0 手持比例、悬停与地面牌堆

- **奥术台**　地面外观为 0.12.1 的 0.8 倍，碰撞半径为 0.7 倍。走近奥术台，检查制作栏左上方大标签中的桌子是否填满更多区域。制作页中入门、普通应显示短杖，精良显示中杖，稀有显示长杖。绕台左右各走一圈，观察人物被挡住的位置是否落在桌腿之间；新放置的预览与落地实体应对齐。
- **九款杖身**　远程执行 `nw_lookkit("blue", 5)` 可取得同用 05 号藤根的六把试杖，覆盖三种长度、晶尖和木尖。第二个参数可换为 1～9。比较同款短、中、长杖上下接缝；捡取、装备、丢下和保存重进后，物品栏图标与实体应仍是同款。
- **粗线条新版素材**　中杖的杖头占约一半全长，短杖约六成、长杖约四成。杖头及木身接口更宽、轮廓加黑，单/双/三尖和木尖/晶尖应容易区分。用同一根法杖装备、丢下再捡起，对比粗细和接缝，再朝空地施法检查出弹点。
- **地面法杖**　执行 `nw_lookkit("blue")` 和 `c_spawn("cane")`。把短、中、长杖放到步行手杖旁，比较同一视角下的高度。三把杖都应从尾端向右倾斜，草痕和贴地阴影应与尾端相接。捡起再放下，并用已有存档中的法杖复测。海面上的法杖应显示漂浮效果。
- **手持与发射位置**　执行 `nw_lookkit("blue")`。固定镜头，在同一站位把同一根杖装备、丢下再捡起，分别对照短、中、长杖。手持的杖沿轴长和宽度应约为地面版本的 1.2 倍；地上的倾角会改变屏幕上的垂直高度。观察三种木纹、头尾接缝和手部握点，朝空地施法核对发射位置。
- **手持法术槽**　执行 `nw_combo("scatter")`，装备并将鼠标移到散弹格。格子应接近物品栏大小；整段说明的下缘要在格子上方。在界面缩放的高低两档、第一格和最后一格分别验证，再在奥术台旁试拖放。
- **建立混合牌堆**　执行 `nw_card("fire")`、`nw_card("frost")` 和 `nw_card("chain")`。把火焰弹丢在地上，鼠标拿着冰霜弹，右键地上的火焰弹选择“叠放法术卡”；再用同样的方式放入闪电。不同种、重复的卡都能放入，每堆最多 25 张。装满后再放入第 26 张，卡片应留在鼠标上；火把不能点燃牌堆。
- **取回与存档**　空手点击牌堆打开5 × 5 格窗口，按需要拿出指定卡。剩一张时牌堆自动散开，最后一张留在原地。也可叠好三张后保存退出再进，确认种类、数量都在。把原版扑克牌与法术卡丢在同一排，对比前后长度。新版法术卡保持原宽，前后长度增加约 51%。观察纸边、落影，以及 1、2～3、4～6、7～25 张四档厚度。

- **卡名**　检查物品悬停、手持槽位说明和奥术台配方。标题只显示法术名；碰撞或定时变体仍显示其完整名称。
- **编辑槽详情**　把鼠标停在手持法杖的法术格上，确认显示木框、卡面图标和属性。在奥术台旁替换该格的卡，保持鼠标不动，信息应随新卡更新。
- **鼠标持卡**　拿起一张法术卡，移到物品栏、背包或法杖编辑槽中的另一张卡上，目标卡详情应隐藏。放下后仍悬停在有卡的格子上，详情应恢复。

## 0.8.5 优先验证（历史记录；当前验收以文末清单为准）

1. **准备**　保存退出并重开游戏，确认 Mod 页显示 0.16.1。白天用普通角色在空地测试。远程控制台分别执行 `nw_combo("double","spark","arrow")`、`nw_combo("quick")`，手动装备第一根。可以直接瞄地面，也可以执行 `nw_range()` 放靶。
2. **单点与转向**　单点一次应只出一组火花弹＋魔法箭。按住 3～5 秒，鼠标从左移到右，后续每组应朝新位置。松手后不再开始下一组。正在抬手的一组按原生动作结算。
3. **移动优先**　持续按住右键，交替按下和松开 A/D。移动时应继续走，停下且动作、冷却允许后自动续发。反过来先按住 D，再按住右键，走几步后只松 D；人物应站定施法，无需重按右键。单独验证抬手刚开始就移动可取消，弹丸已离手再移动则保留该发。留意橡皮筋回拉、角色被按回原位、说“我做不到”或一次补发多组。
4. **等待与停止**　装备双重测试杖后，远程执行 `nw_saveprobe()` 给当前杖设置 30 秒诊断冷却。持续按住右键，确认冷却期间不反复抬手，到期才发。再做一次，在冷却结束前松开，这次到期不应补发。缺蓝等待可以用 `nw_testkit()` 领取并装备 **double** 杖后执行 `nw_manaprobe()`；它的蓝池回复较慢，沿用现有的按牌序跳过付不起的卡规则。
5. **理智**　装备第一步的双重杖，满蓝时单点一次，两弹合计应扣 **0.75 SAN**。换 **quick** 杖单点一次，应扣 **0.1 SAN**。检查小数可在出手前后分别执行 `local p=ConsoleCommandPlayer(); p.components.talker:Say(string.format("SAN %.2f",p.components.sanity.current))`。选白天、远离理智光环和恢复装备，以免自然变化干扰读数。
6. **零理智与旧杖**　在测试世界执行 `ConsoleCommandPlayer().components.sanity:SetPercent(0)`，然后朝空地施法，应照常出弹，施法本身不扣血或饥饿。测试后可用 `ConsoleCommandPlayer().components.sanity:SetPercent(1)` 回满。重进旧世界，悬停旧杖应显示“理智转化率 20”，原有回蓝、法术槽和牌组保留。

### 周末双人验收：A/B 分工

两人使用相同版本。房主或管理员开启开发者选项，在空地执行 `nw_testscene("duo")`；朋友无需管理员权限，只需按箱名分别领取 A/B 用品。每组两人各有一套法杖、工具和材料，不必来回借杖；木牌是现场简要步骤，下表是完整验收。

A/B 是操作角色，不固定等于房主/客机。第一轮 A 操作、B 观察或触发；再交换角色，让远端客户端也完整做一次。记录谁是房主、谁是客机、延迟和移动预测开关。使用普通角色、测试伤害时脱甲，保持足够生命；测试自身载荷时不要开无敌。

建议顺序：duo_ui → multiplayer → duo_motion → duo_presence → duo_cleanup。PvP 关闭时先做默认矩阵，开启时另开一轮；跨分片项目需启用洞穴。离线测试让客机担任放置者、房主留在线；本地房主退出通常会关闭世界，不能用它代替“施法者离线而世界继续运行”。专用服务器下可交换两人做离线测试。

清理长时测试最后单独做：分片不能混入其他永久移动实体。等待时两人保持在线并远离旧卵，可在远处做纯界面测试；不要顺手放其他晶体或卵，也不要为了查看结果走回去重置计时。

### 休眠清理：独立条件与计时验收

在仅含测试实体的分片开启「永久移动实体自动清理」。先用 `nw_testcleanup(20)` 生成 20 个零速但具有追踪能力的卵；附近不要放敌人。命令报告本次生成数与当前计入总数，不修改配置、计时或阈值。已有移动晶体/卵也计入总数，有限寿命星体不计入。

1. 所有玩家离开该区域，按原版活跃/休眠状态计时；不要用固定 64 单位代替判定。超过 16 分钟后总数仍为 20，旧卵应保留。
2. 在另一处执行 `nw_testcleanup(1)`，不要先返回旧卵处；下一次检查应清除连续休眠满 16 分钟的旧卵，新卵保留。可用远程控制台查看 `TheWorld._nw_permanent_motion_cleanup.count`，避免亲自靠近重置计时。
3. 另一轮在未满 16 分钟前进入旧卵的活跃区，再离开；旧计时应重置，不能沿用上轮时长。
4. 不超过 20 时持续休眠超过 20 分钟，计数封顶 1200 秒。保存退出后离线时间不累计；重进后从已保存时长继续。该数值上限与恢复逻辑已有 Lua 自动测试，实机长时测试仍需按上述流程验收。
5. 关闭清理设置重启后重复放置与离开，不应自动清理；开启时清理也不爆炸、不释放载荷。

### 必测边界与结果记录
