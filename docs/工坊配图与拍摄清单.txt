三、游戏内拍摄准备

1. 使用独立的拍摄/测试世界，启用当前本地版本。
2. Mod 配置开启「开发者选项」；「开发加载自检」保持关闭。
3. 房主或管理员打开控制台，确认是「远程」模式。先输入 nw_help() 确认入口可用。
4. 下文命令逐行复制执行；每次 nw_combo 都是领取一根新杖，需要自己装备。
5. 背包留空，白天找平坦空地；星体单独在黄昏/夜晚拍。命令不会自动改时间。
6. 如果游戏中缺少最新命令/素材，退出游戏后在项目根目录执行：

   .\.venv\Scripts\python.exe tools/install_mod.py

   再重新启动游戏和世界。本轮没有代为执行安装。

开发试杖说明：
  nw_combo 为固定 12 槽、600 法力、80/秒回蓝、基础施放间隔 0.45 秒、
  基础充能 0.6 秒、非乱序、同发 1。卡牌仍采用实际规则，不额外加伤。
  正常游玩需要获取卡牌、寻找适合的法杖；素材不要暗示出生就能获得这些属性。
  视频/展示图可统一小字注明：
  「演示使用开发试杖展示组合效果；实际法杖属性依获取结果而定。」
  English: Demo loadouts use a developer wand; acquired wand stats vary.

四、M01：同一组靶，四种施法

准备命令，逐行执行一次：

nw_range()
nw_combo("long_life","spark")
nw_combo("homing","long_life","spark")
nw_combo("trident_cast","fire","arrow","frost")
nw_combo("arrow_hit","chain")

按领取顺序装备：
  1. 续航铭文 → 火花弹。
  2. 追踪 → 续航铭文 → 火花弹。
  3. 三叉施法 → 火焰弹 → 魔法箭 → 冰霜弹。
  4. 魔法箭·碰撞 → 连锁闪电。

录制动作：
  第一、二把在同一站位朝靶排侧面偏一个身位发射，录直线飞过与追踪转弯。
  第三把瞄准前方，录三向发射。第四把直接击中前排，录箭命中后释放连锁闪电。
  每段多录 1–2 秒起止空白，后期剪成短循环，不要在成片里显示控制台。
  保留法杖栏，使观众能看到「换卡」与「效果变化」的对应关系。
  追踪并非必定命中，需要在镜头里试一次合理角度。

如要拍正文的近战载荷示例，可另领一把：

nw_combo("arrow_hit","whirl")

它对应「魔法箭·碰撞 → 旋斧攻击」。不要用 arrow_hit + explosion 代替，
explosion 是命中修饰，后面仍需要一个攻击法术才能在载荷中发挥作用。

nw_range() 按人物当前朝向布置靶，有一只友方治疗靶；不要拿治疗靶测试敌人追踪。
普通测试靶有 1000 血，会被击破。重复执行是再生成一排，并非重置原来的靶。
必要时换一处空地，不要在同一位置反复叠靶。

五、M02：奥术台、装卡界面与地面牌堆

准备命令：

nw_hudkit()
nw_card("homing")
nw_card("damage_up")
nw_card("arrow_hit")
nw_card("chain")
nw_card("trident_cast")
c_give("featherpencil",2)
c_give("nw_blank",4)
c_give("nw_dust",8)

nw_hudkit 自带奥术台，给 2、7、12 槽试杖和火焰弹卡。
7 槽试杖初始已有火花弹和魔法箭；演示「追踪 → 火花弹」时，先取下魔法箭，
再把追踪放到火花弹前面，避免旧卡参与下一轮施法。
先装备 7 槽杖，靠近奥术台，把卡拖入编辑栏，截一张能看清卡序的画面。
想演示最简单的「换卡就不同」，也可只拍在火花弹前插入追踪的前后两帧。

若要补一张三建筑实机合照，在空地执行这一整行：

local p=ConsoleCommandPlayer(); local x,y,z=p.Transform:GetWorldPosition(); local e=SpawnPrefab("nw_engraver"); e.Transform:SetPosition(x-4,0,z-3); local f=SpawnPrefab("nw_disassembler"); f.Transform:SetPosition(x+4,0,z-3)

人物朝向和镜头旋转会影响左右位置，可走位选景。不要让建筑遮挡编辑框。
制作牌堆：把一张法术卡放到地上，鼠标拿另一张卡，右键地面卡片叠牌，
再加入一两张。空白卡和粉尘不是法术卡，不用于这一步。
另拍一张关闭编辑框的建筑/牌堆合照，不要把所有窗口同时打开。

六、M03：镰刀收草

领取法杖：

nw_combo("target_nature","edge_voidcloth_scythe")

在空地生成六株草，下面是一整行：

local p=ConsoleCommandPlayer(); local x,y,z=p.Transform:GetWorldPosition(); for i=1,6 do local e=SpawnPrefab("grass"); e.Transform:SetPosition(x+1+i,0,z) end

这排草沿世界 X 正方向排列；看清草的位置再朝整排草施法。
预留背包空间，人物不要挡住第一株草。录下飞出、沿途采收、近处收获入包。
已收割的草不会因为再次施法立即长回；重拍用新一排草或回到拍摄前存档。

可选补拍钓鱼，优先使用场景中的现成池塘：

nw_combo("edge_fishingrod")

若没有池塘，在适合的空地用 c_spawn("pond") 生成一处，再走开瞄准它。
渔获落在靠近施法者的池塘边，不是直接飞到人物脚下。

七、M04：移动星体与巨化

在远离靶、草、建筑的空地领取：

nw_combo("speed_up","spiral","edge_yellowstaff")
nw_combo("edge_opalstaff")
nw_combo("giant_shot","edge_opalstaff")

第一把：加速 → 螺旋弹道 → 唤星法杖。向空地方向释放，拍矮星移动和光圈。
后两把：普通唤月与单张巨化唤月，保持相同人物距离、镜头与时间条件分别拍。
最好分别使用同一地点的拍摄前存档，避免两颗星体的光照互相叠加。
单张巨化是 2.5 倍，伤害数值不因此提高。

可选拍随行效果：

nw_combo("target_self","homing","edge_opalstaff")

该组合使星体追踪自身，实际会按追踪运动规则移动，不要写成永远贴身的宠物。
推荐先拍更容易构图的螺旋矮星。

唤星最低冷却 240 秒，唤月 60 秒，试杖也保留此限制。不要靠连续施法录星体连发。
重新领杖不会移除已经生成的星体；换空地或回拍摄前存档，避免满地光源。

八、M05：陶笛与弦琴，保留声音

准备命令：

nw_combo("kantele_dsharp","kantele_e","kantele_g","kantele_b","kantele_g","kantele_e")
nw_combo("note_c","ocarina_d","ocarina_e","ocarina_g","ocarina_e","ocarina_d")
nw_combo("pitch_octave_up","kantele_dsharp")

依次为：
  弦琴 C4—E4—G4—B4—G4—E4。
  陶笛 C4—D4—E4—G4—E4—D4。
  升八度的弦琴 C5。

kantele_dsharp 是兼容旧存档保留的内部 ID，当前显示和发声为弦琴 C4。
站定后按住右键可按顺序弹奏；逐次单击更容易控制录制节奏。
可以在安静营地拍，降低背景音乐，保留游戏音效。先演奏两种音色，再加升八度对照。
这只是短乐句示范，不宣称它具有完整乐谱编辑器或精确自动节拍器。

九、素材规格与回填

建议先保留 1920×1080、30 或 60 fps 的原始录像，再裁切/压缩。
成品动图建议宽 800–960 px、约 12–18 fps，每段只表达一个变化；
4–8 秒适合一般功能，首屏连招可稍长。尽量压到几 MB，同时保证卡牌仍可读。
以上是本次制作建议，不是 Steam 平台硬性限制。
UI 截图保留文字清晰，裁去空旷地面；中英文尽量使用同一张无内嵌文字的画面。

建议交付命名：
  01-combos.mp4 / 01-combos.gif
  02-wand-editor.png
  03-harvest.mp4 / 03-harvest.gif
  04-moving-star.mp4 / 04-moving-star.gif
  05-instruments.mp4 / 05-instruments-cover.png
  06-stations.png（可直接使用现有 lineup.png 原文件）

素材上传至你用于工坊介绍的图片托管位置后，取得可公开读取的图片直链，
按第二节的位置插入 [img]图片直链[/img]，再加短图注；视频使用实际可访问的视频链接。
不要把本地磁盘路径、Steam 作品展示页地址或预览里的占位文字放进 [img]。
先预览一张静图和一张动图，确认 Steam 页面能显示、动图能播放，再替换其余位置。
英文正文对应章节插相同的无文字素材，使用英文图注。

回填后在项目根目录检查字节数：
  .\.venv\Scripts\python.exe tools/steam_workshop_metadata.py
此命令只预览，不连接 Steam。英文预留空间较少，若 URL 较长，优先删减重复说明。
实际上传请沿用 docs/发布流程.txt 的工坊更新步骤；本清单不自动发起上传。
