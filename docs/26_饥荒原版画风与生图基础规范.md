# 饥荒原版画风与生图基础规范

更新日期：2026-11-09。用于「织法之杖」后续物品、建筑、卡牌主图、场景与工坊宣传图片生成。以下结论依据本轮用户提供的五张图片及本机原版素材样本提炼，作为本项目的工作规范；具体形象、颜色、视角和构图仍以各次任务要求为准。

共同基础是清楚的剪影、有主次的手绘墨线、简化而可信的体积、明确色块，以及按材质和结构分布的细节。风格强度应随素材用途调整，不能把某张宣传图的纸纹、配色或边框套用到全部图片。

## 造型与结构

先用整体剪影识别对象，再用少数部件解释功能。原版机器的木脚、轮子、球体、旋管各有明确外形；火魔杖的红色杖头和细长杆体很快就能识别。适度夸张关键部件，减少无助于识别的装饰。

大弧线、尖角、折线和少量卷曲共同形成节奏。木件可以略歪，圆形可以不完全规整，左右可以不完全对称；连接、受力和支撑仍需成立。细长杆件可有弯曲，不能让接口脱节或各段朝向互相矛盾。

场景可以使用带手绘感的透视，物件必须共享可理解的桌面或地面。不能把造型夸张变成每个物件各自漂浮、扭转或朝向失控。

## 线条层次

| 线条用途 | 绘制方式 | 样本中的表现 |
| --- | --- | --- |
| 外轮廓 | 总体较重，粗细有变化，转折有尖收与少量破笔 | 木箱、锅、宝石的外沿 |
| 遮挡与接缝 | 重要部位可接近外轮廓粗度，局部黑块压住前后关系 | 锅盖与锅身、冰箱门框、叠层金属 |
| 内部结构 | 比外轮廓轻，数量有限，明确分瓣、拼板、关节和切面 | 南瓜分瓣、机器铆钉、宝石切面 |
| 材质笔触 | 更细、更疏，方向服从材质与体积 | 木纹、短划痕、皮膜细线 |
| 局部排线 | 按暗面需要聚集，允许局部密集，不平均铺满 | 锅身暗侧、宝石下缘、落地阴影 |

线条的手绘感来自有节奏的粗细、转折、少量复笔和不完全规则的边缘。不要对每条线添加相同毛刺。黑色楔形和实黑小块可以加强转折；大面积描黑要服务于形体或遮挡。

图片1和原版地面物件的外轮廓通常比宣传动画人物更有重量。线宽根据画面尺度和用途选择，不设适用于全部输出分辨率的固定像素值。

## 色块与明暗

先建立主体固有色、主要亮面、主要暗面，再放少数高光。金块以亮黄、较暗黄褐和浅色折面成立；机器与冰箱用灰色、蓝灰色分面；南瓜用橙色主体、暗色侧面和深黑孔洞表现体积。无需用连续复杂渐变模拟真实表面。

允许轻微色面变化、局部柔和过渡和背景气氛层。主体仍应保有清楚分面，避免被柔光、厚重环境光遮蔽或细腻写实反射抹掉形状。

高光本身是绘制出来的形状。宝石可以出现利落白色长条，金属可以使用短粗白线和浅色亮片，弧面可以使用少数弧形亮斑。亮度可以很高，但轮廓与数量需要受控。

## 色彩关系

原版样本并非一律低饱和。金块和机器上的球体可用很鲜明的黄色；蓝宝石、紫宝石与红色杖头也有明确彩度。宣传截图中的橙色南瓜、浅黄头发和白色眼睛同样鲜明。

木材、石材、环境和次要结构可以用灰褐、灰绿、蓝灰、暗紫等安静颜色。用明度、色相和面积分配区分主次，保留必要的彩色焦点。场景色调按环境决定；泛黄纸色、暖棕滤镜和暗绿色森林都不是全局固定配置。

## 材质与纹理

| 材质 | 推荐表现 | 细节应放在哪里 |
| --- | --- | --- |
| 木材 | 几条顺着长轴的长短线，少量分叉或节疤，端面短纹 | 木板方向、断面、接缝；留出完整木色面 |
| 金属 | 大色块分面，接缝、铆钉、短划痕，明确浅色亮条 | 边缘、接合处、曲面暗侧和反光位置 |
| 石材 | 不规则块面、深浅转折、少量裂缝 | 石块交界与体积转折；避免写实砂砾布满全表面 |
| 宝石 | 少数大切面、明暗色面、尖锐或略不齐的白色亮条 | 切面和转折；避免复杂折射与内部星空 |
| 皮膜 | 骨架或支撑线清楚，薄膜以少数折线和局部暗面表现 | 蝙蝠翼的骨条、边缘与受拉位置 |
| 布料 | 大褶皱、局部缝线，宽松处与受力处有所区别 | 折叠、束缚与接合位置；不铺满细织物噪声 |
| 纸张 | 浅色完整纸面、适度弯曲与边厚，内容图形明确 | 边缘、折叠和必要的书页层；精制卡牌保持整洁 |
| 玻璃 | 清楚瓶形、少数浅色反光，瓶内物体或填充色可读 | 瓶口、弧面和内容物边界；避免摄影式复杂透明折射 |

木材、金属、石材、宝石、皮膜可直接对照本轮原版贴图。布料可参考宣传截图；纸张和玻璃行是将共同画法应用到本 mod 卡牌、书本和粉尘瓶的制作建议。

局部排线可以很密，例如锅身暗侧；大色面也可以很干净，例如金块和木箱。纹理密度由材质、受暗位置、画面尺度和主体重要性共同决定。不要让木桌、书页、宝石、玻璃共享同一种划痕与颗粒。

## 空间与阴影

原版地面物件常带由黑色短线和碎块构成的贴地阴影，线条总体沿地面铺开，疏密不均。它们解释接触与重量，不等同于绕着物体外沿的一圈黑色光晕。用于完整场景时应统一方向、距离和遮挡关系，避免机械复制每件素材原有的独立地面阴影。

宣传场景以遮挡、大小、明度和背景简化建立纵深。远景树木可以压成暗剪影，雾层和光线可以柔和；主要人物、道具和关键动作保持清楚。不要让背景和主体使用相同的线条重量与纹理密度。

## 可复用基础提示词

以《饥荒》《饥荒联机版》原版二维手绘美术为视觉依据。画面具有古怪、略阴郁而带幽默感的气质，以清楚的剪影、有节奏的墨线、可辨认的大色块和有选择的材质笔触建立统一风格。

造型使用明确的大弧线、适量尖角、轻微不对称和有目的的比例夸张；边缘可略歪，局部可有卷曲和尖收，物件的支撑、连接、朝向与透视必须清楚。保留主体最有辨识度的形状，缩小后仍能读懂。

线条具有主次：外轮廓与重要遮挡接缝较重，内部结构线较细，材质细线更轻。转折处可出现黑色楔形、少量复笔与自然收尖，控制不规则程度，保持线条明确。根据最终显示尺寸调整线宽；宣传场景中的主体轮廓可以比独立小图标更轻。

以物体固有色和少量明确的亮面、暗面塑造体积，允许局部轻微色差与柔和过渡。高光画成有形状的白色、奶白色或浅色块、短线和长条。木材、石材与环境可用灰褐、灰绿、蓝灰等安静颜色；金属、宝石、火焰和关键标识允许使用鲜明的黄色、红色、蓝色、紫色或其他与对象一致的颜色，主次色彩服从识别和构图。

纹理随材质和形体方向分布：木纹沿木材长轴，石材以块面与少量裂缝表现，金属用接缝、边缘短划痕与明确高光，宝石用少数大切面和利落亮条，布料与皮膜用褶线、缝线和张力结构。排线集中在必要的暗面、转折、接缝和局部接触阴影，保留完整、干净的大色面。纸张和玻璃根据其自身材质表现，表面纹理保持克制。

根据用途组织轮廓、遮挡、明度、色彩和疏密。主要形状清楚，次要区域减少细节；宣传图的环境可使用简化剪影、低对比色层与轻微雾气，独立建筑和物品栏贴图按各自规范处理透明背景与阴影。物件内部保持可信的光线方向与连接关系。手绘感来自造型和笔触选择，材质之间保持明确区别。

### 避免项

避免：整幅统一羊皮纸底纹、均匀噪点、强烈泛黄滤镜、所有表面同样脏旧、到处添加破口裂纹、覆盖全图的密集排线、所有线条等粗、每条边缘都重复描黑或故意起刺、精确光滑的矢量几何感、复杂写实反射、塑料般的三维渲染、过度环境光遮蔽、无依据的强泛光、细节淹没剪影。边框、文字、符文、粒子和磨损程度仅按具体画面要求添加，不作为固定风格配件。不要复制视频压缩块、低分辨率锯齿或参考板标签。

同一物体需要多类输出时分别编写Prompt。工坊图标归宣传图，物品栏图标归游戏内物品栏贴图，建筑的制作栏图标也归游戏内物品栏贴图。
不把一次任务的桌面、卡牌、边框、暖纸色或魔法光效写成所有图片的固定要求。

独立可复制版本见 [DST生图基础提示词.txt](DST生图基础提示词.txt)。

## 后续生成与验收

1. 每次新的美术任务先读取共同规范、三类中对应的执行规范和基础提示词，明确最终观看尺度及透明背景需求，再选择对应原版参考；不得只凭旧Prompt或上次会话记忆跳过阅读。
2. 把参考图的作用分别写成画风、物件身份、构图或材质，保留已经确认的卡牌轮廓、法杖比例、颜色与符号。
3. 采用基础风格段和一个用途附加段，再补本次主体、动作、物件数量、摆放、镜头和文字要求。新增细节应有识别或构图目的。
4. 检查剪影是否先于纹理被读到，线条是否有主次，不同材质是否有不同画法，光线和接触关系是否成立。
5. 在目标观看尺寸检查可读性。工坊图需缩略检查；小图标必要时单独简化。将微小噪点、断裂黑线和无法辨认的装饰清掉，保留主要形状与色块。
6. 每次修订只针对明确偏差，例如减弱全局纸纹或减细内部线条，避免改风格时同时改变已经正确的物件身份与布局。
