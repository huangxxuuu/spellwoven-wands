# 法杖编辑与标签筛选最终方案交接

归档日期：2026-11-07（Asia/Shanghai）。记录本次会话的最终实现，供聊天归档后继续开发。归档时工作区 `mod/modinfo.lua` 为 **0.25.16**，本地安装目录的版本号仍为 **0.25.15**；本会话按文件同步了相关 Lua，不能据此认为整个工作区已完整安装或发布。

制作栏最终采用 **主类筛选、两行标签、标签单选**，词表固定为 **24 个双字标签**。法术自身仍可拥有多个标签。“伤害”标签仅用于修饰主类。法杖可编辑状态下使用原生物品容器处理转移操作。

## 1. 用户确认的制作栏行为

- 只在奥术台 `nw_workbench`、武器刻印台 `nw_engraver` 的制作站页面启用，并尊重本机设置 `crafting_class_filter`。原生搜索和其他制作页面保留原有行为。
- 主类选项为全部配方、基础法术、法术修饰、施法控制。“全部”是解除主类限制，不是第四个卡牌主类。
- 根据本站完整配方表隐藏没有制作项的主类。不能按材料是否足够或当前标签结果隐藏主类。目前刻印台只显示全部、基础。
- 默认不选标签；点击一项进行过滤，点击其他项替换选择，再点已选项取消过滤。
- 每个制作站、每个主类分别记忆选择。切换主类、暂离制作站页面、搜索后返回时保留；关闭制作栏半屏抽屉后清空。
- 标签候选来自当前制作站和主类的完整配方表。空结果不能把标签行一起隐藏，否则玩家无法取消条件。
- 标签最多两行，保持正常字号；两行放不下才翻页，一页包含两行。极长的单个翻译名称可单独缩放，不能缩小整个标签区。
- 鼠标悬停标签不显示提示文字。选中状态使用颜色、底衬和下划线。
- 手柄左右在当前行移动，上下按最近横向位置切换两行；第一行向上回主类，第二行向下进入配方列表。翻页箭头也可通过手柄访问。
- 同一候选列表更新选中状态时保留按钮身份、焦点和页码；更换候选列表时从第一页显示。反复开关不能累计布局偏移。

**已替代的方案：** 39／34 个标签、单行标签、多标签 AND 筛选均不是最终界面设计。底层 `Filter.filter` 仍能处理集合交集，但界面入口清空旧选择再设置新选择，实际只允许零项或一项。不要根据旧日志里的 `AND tags` 恢复多选。

## 2. 最终标签及语义边界

以下分组只便于阅读，不是新增主类。中文名称全部为两个字。

| 查找方向 | 标签 |
| --- | --- |
| 攻击特点 | 近战、范围、元素、位面、爆炸、控场 |
| 功能用途 | 位移、恢复、防御、工具、音乐、照明 |
| 参数调整 | 伤害、速度、寿命、目标、法耗、充能 |
| 释放机制 | 弹道、追踪、穿透、多重、复制、触发 |

标签目的是细分主类、加快寻找，不是罗列全部内部参数。普通攻击有伤害、耗蓝、速度或持续时间，不因此获得对应的修饰标签。其他卡临时赋予的效果也不写回固有标签。

| 标签 | 必须保持的边界 |
| --- | --- |
| 触发 | 通过碰撞、定时、击破等条件释放后续法术，或赋予这种能力。普通命中爆炸、吸血、音符回声不算。标签 ID 为 `trigger`，没有更改法术本身的载荷机制或存档 ID。 |
| 伤害 | 仅限玩家主类 `primary_class == "modifier"` 中调整伤害、暴击、条件增伤的卡。不能只检查内部 `kind`，部分复制控制卡的 `kind` 也是 modifier。 |
| 范围 | 实际区域攻击、横扫、群体效果、沿途连续采收或扩大作用范围。索敌半径和护盾环绕半径不算。 |
| 元素 | 火焰、寒冷与温度、电击、湿润及针对潮湿的专门作用。位面单列，不能按贴图颜色推断元素。 |
| 恢复 | 回复生命或理智；仅免除原装备的持续理智消耗不算恢复。 |
| 工具 | 实际砍挖、采集、耕地、浇水、捕鱼等工作，也包括能破坏可工作目标的爆炸。原工具名称不自动代表法术保留该动作。 |
| 位移／控场 | 移动施法者归位移；击退、拉拽、减速、冻结、嘲讽或打断敌人归控场。 |
| 照明 | 实际提供光源，发光贴图和火焰粒子不算。 |
| 多重／复制 | 多重表示额外抽卡并组织同组施放；复制表示重复输出。基础法术自带多枚弹体或发射普通侧弹不自动属于二者。 |
| 弹道／追踪 | 弹道涵盖路径、散射、方向分布、侧向分裂、抛物线、返航等。追踪要求飞行中持续朝目标转向或推进，单次自动索敌不算。 |

音高、音符并入音乐；治疗和理智回复合并为恢复；火焰、寒冷、电击、潮湿合并为元素；散射并入弹道；碰撞、定时、击破载荷统一为触发。远程、地面、瞬发、尺寸、修饰、采集不再作为独立筛选项。

少于 3 张不自动删除。按当前设计卡统计，位移 2、防御 2、法耗 1、充能 2，因寻找目的明确而保留。不要用可制作数量代替设计卡总数，例如复制有 3 张设计卡、只有 1 张可制作。

### 伤害标签的最终成员

共 7 张，全部属于修饰主类：

| 法术 | ID |
| --- | --- |
| 伤害强化 | `damage_up` |
| 沉重一击 | `heavy_shot` |
| 轻盈一击 | `light_shot` |
| 潮湿破绽 | `wet_weak` |
| 近战破绽 | `melee_mark` |
| 无害载体 | `harmless` |
| 暴击铭文 | `crit_rune` |

蓄势光球、暗影回旋镖、四倍施法已移除此标签。伤害标签包括减伤和清零，不限于正向增伤。

## 3. 全量法术核查与维护入口

核查覆盖 **220 个定义**，含 **186 张当前设计卡**及旧档兼容定义；其中 **149 张法术可制作**。专服检查中的 **166 个制作站配方**还含材料、法杖等，不是法术卡数量。

- [逐项核查清单](../test_reports/card_tags_audit.txt)：完整语义、各标签计数、逐卡标签和效果说明。
- [机器可读数据](../test_reports/card_tags_audit.json)：同源 JSON。
- [导出工具](../tools/export_card_tags.py)：执行 `.\.venv\Scripts\python.exe -X utf8 tools/export_card_tags.py` 更新；不能只改导出结果。
- [实际规则](../mod/scripts/nw/card_tags.lua)：主类身份来自 [card_visuals.lua](../mod/scripts/nw/card_visuals.lua)。

归档时有 8 个法术没有额外标签：火花弹、魔法箭、重能量球、蓄势光球、荚刺哨株、蜂群突袭、萤虫伴飞、旋转的风扇。它们仍能通过主类找到，不为“全覆盖”强贴不合适的标签。

需要保留的核查结论：

- 蝙蝠棒能吸血，归恢复；临时暗影槌从原版一级开始，吸血为零，不归恢复。
- 哑铃飞行中穿透、落地有原版范围攻击。冰铃还带元素、控场，火铃带元素，热铃不能因名称就归元素。
- 蘑菇孢球被击破后有范围爆裂，归范围、爆炸，不归触发。
- 局部雷云每次只选一个目标，连锁闪电逐跳选目标，不因搜索半径归范围；电击环实际作用于区域内目标，保留范围。
- 双侧余烬的侧弹没有灼烧属性，归弹道，不归元素或触发。
- 旋斧、长矛突刺、沼泽鞭击补齐实际范围。环绕补齐主要延寿效果。巨化扩大实际作用范围，但不增伤或延寿。
- 暗影收割者保留沿途采收，归工具、范围；原武器位面伤害已从法术定义移除，不能照搬。
- 爆炸修饰和火药能点燃并破坏可工作目标，保留元素、工具。打火机烹饪、鱼食诱鱼不因此归工具。

## 5. 法杖编辑容器与预览居中

[wand_container.lua](../mod/scripts/nw/wand_container.lua) 建立真实 `container`，编辑槽由原版 `ContainerWidget`／物品槽处理。标准转移操作及沿用这些接口的客户端扩展可以走同一条路径，不再单独只实现 Shift 加左键。

- 预留 12 个网络槽，只显示和使用法杖实际容量内的槽位。
- 服务端检查法杖装备归属、玩家存活和工作台范围。失去编辑权限时关闭容器，阻止未经许可的转移。
- 真实卡牌实体与法杖序列化数据双向同步，保留实例标识和来源。
- 原法杖存档仍是权威数据，容器投影不重复保存，避免重进后复制卡牌；`_nw_syncing` 防止同步事件递归。
- 关联入口：[nw_wand.lua](../mod/scripts/prefabs/nw_wand.lua)、[nw_wandpanel.lua](../mod/scripts/widgets/nw_wandpanel.lua)、[原生容器测试](../tests/test_wand_container_native.py)。

服务器启动曾因 `itemtestfn` 读取 `_nw_capacity` 报错：入参是容器组件或副本，实体字段应从 **`container.inst._nw_capacity`** 读取。当时安装目录仍存在旧实现；同类问题必须同时核对源码和游戏实际加载目录。

原生接口兼容不等于所有第三方 Mod 已实测。如果具体快捷键 Mod 不兼容，先检查是否限制了容器类型或替换了原生接口。

[nw_itemhint.lua](../mod/scripts/widgets/nw_itemhint.lua) 使用动画 `GetVisualBB()` 的可见边界居中法杖，保留统一 **0.28** 缩放，并按标题／副标题区域高度计算纵向中心。短杖不再按模型原点偏在底部；不要恢复只针对个别长度手调偏移的做法。编辑格子间距等相邻工作见[信息面板与编辑框交接](24_信息面板与法术编辑框调整_会话交接.md)。
