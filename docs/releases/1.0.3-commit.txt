Release v1.0.3

织法之杖 1.0.3 完整更新记录
整理日期：2026-11-09
对比基线：2026-11-08 正式发布的 v1.0.2 冻结包。
范围：当前工作区相对正式发布包的增量，按最终功能整理。
发布版本：1.0.3。

1. 新增粉尘收纳盒
可随身携带的首饰盒式粉尘容器，支持在人物物品栏、背包内和地面打开。
只有一格，只接受奥术粉尘，使用原版无限堆叠机制；取出后恢复普通粉尘堆叠规则。
在奥术台制作：木板×1、金块×2、蛛丝×2、奥术粉尘×4。
支持多人开关、背包嵌套存档，以及空、半满、全满的状态显示。
加入独立物品栏图标、完整盒盖开合动画及贴地阴影，保留小巧的凸盖首饰盒外形。

2. 新增奥术余烬灯
固定地面灯具，提供粉尘的持续消耗渠道。
炼金引擎解锁：石砖×2、金块×2、紫宝石×1、奥术粉尘×4。
左键打开容器，右键点燃或熄灭。容器同样只有一格，仅接受粉尘并支持原版无限堆叠。
点燃时每个粉尘持续60秒；熄灭暂停消耗，不足一分钟的燃烧进度随存档保留。
取空后自动熄灭，重新添加粉尘后手动点燃。休眠区域按游戏时间结算，关服时间不计入。
半满与全满提供两档照明范围，使用紫色更明显的柔和灯光。
加入空、半满、全满外观，以及点燃、持续燃烧和熄灭动画。
燃料围住灯芯，满料时覆盖固定环；火焰从灯芯处燃起，位于托盘和灯芯前方。
锤拆掉落未消耗的粉尘，并按原版规则返还制作材料。

3. 两种容器的装量规则
空：数量为0。
半满：数量大于0，且不超过粉尘普通堆叠上限的两倍。
全满：数量超过普通堆叠上限的两倍。
统一读取粉尘的堆叠上限配置；当前上限40，因此1至80个为半满，81个起为全满。
以后修改堆叠上限并重启世界，两者会使用相应的新阈值；灯的照明档位同步变化。

4. 地面表现与交互完善
粉尘、核心等材料增加贴地阴影；当前采用素材内绘制的阴影，库存图标不带地面阴影。
收纳盒优化关闭时盒盖与盒身的对齐、凸起厚度、开合动作和不规则接地阴影。
余烬灯优化石座贴地效果、满料边框、灯芯与火焰覆盖关系；熄灭采用专门绘制的火焰变化。
统一新物品的游戏内显示尺寸、放置预览和交互范围。
修正灯的碰撞范围过大：碰撞按石座独立设置，不随灯身视觉缩放放大。
灯的鼠标选取恢复原版默认命中方式。

5. 粉尘设定文案与本地化
描述同时涵盖研磨宝石与生灵残留魔力两种已有来源：
“宝石中沉睡的魔力，研磨后凝成晶粉；吸纳游离魔力的生灵陨落时，也会留下这样的余烬。可用于制杖与浸染空白卡。”
新增两种物品的中英文名称、配方说明与检查对白。
本次是描述完善，没有把既有怪物掉粉机制列为新增功能。

6. 模组图标
更新模组列表图标，并新增英文版图标。
前端根据游戏语言选择中文或英文图标。

当前实现参数（供验收和后续调整）

余烬灯世界外观和放置预览：1.65倍。
余烬灯碰撞半径：0.4；放置间距：2。
