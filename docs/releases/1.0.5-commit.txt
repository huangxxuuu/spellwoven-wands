2. 分解炉地面动画与光照
新增独立 nw_furnace_wave 动画资源，拆分弧段、晶体、符文和碎片进行运动。
grow 60 帧／30 fps／2 秒，loop 60 帧／30 fps／2 秒循环，release 18 帧／30 fps／0.6 秒。
使用贴地背景层，修复分解炉后半圈覆盖炉体的问题。扩散与光照共用阶段进度，客户端同步经过时间和状态序号，处理独立时钟、延迟、重复状态和重新启动。
无可分解物品、取消操作与正常完成均进入视觉消散；分解逻辑立即停止。消散为弧段原地裂解、局部运动和淡出，光照强度同步降低，不使用中间方案的整圈缩回。
提前中止时按当前扩散范围消散，完成或移除时清理周期任务和本地特效。保留原有扫描、分解时间与玩法。
新增特效构建、预览工具与状态／编译动画回归测试。

3. 法术实体限制角色提示
实体限额拒绝生成、不限时驻留实体替换或有效载荷深度限制实际触发时，由相应施法者发出角色提示。
三句中英文台词轮换，每位玩家最多每 30 秒提示一次；普通清理、编译预览、存档恢复不触发。
个人设置新增“限制触发时角色说话”，默认开启，可单独关闭，保存到本机并在进入世界时同步。
服务端仅接受当前玩家自身的布尔偏好；本地异步读取、连续写入和重连行为有回归覆盖。

4. 法术测试拳击袋
空手右键在连击、10 秒测试、30 秒测试间切换；测试中或结束后先重置相同时长，再次右键可切换。
右键文字为“连击”“10秒测试”“30秒测试”“重置”。修复与分解炉重复注册 SCENE/inspectable 导致入口被覆盖的问题，沙袋使用原版 health 组件动作入口，两种加载顺序均有测试。
选定测试者的首次有效命中启动 10／30 秒计时，累计该测试者的有效伤害；截止时刻及之后的伤害不计入。
DPS = 累计伤害 ÷ max(1 秒, 首次命中至当前的已过时间)，每 0.1 秒刷新，结束后固定为总伤害除以所选时长。已替代中间的最近 1 秒滚动 DPS 实现。
窗口耗蓝和施法次数从准备测试时开始累计，包含首发弹体和首次命中前的空放，截止于伤害测试结束；成功的零耗蓝施法也计一次。每次施法计一次，不按弹体或命中数量重复计数。
伤害、DPS、窗口耗蓝、施法次数各占一行。头顶测试文字使用常规提示的 UIFONT 与白色，保留 16 字号；网络同步数值，由各客户端按语言生成文字。
仅一个测试者拥有当前测试，每位测试者同时至多占用一个准备中／进行中的沙袋；其他玩家不能抢占，结束后允许接手。
测试者超过 30 世界单位时，准备中、进行中、结束状态均清空并返回连击模式，每 0.1 秒检查；恰好 30 单位保留。死亡变幽灵、断线、沙袋烧毁或移除时释放归属。
支持直接生命伤害及带施法者标记的原版延续实体／武器归属，不猜测无法归属的环境伤害。
测试状态不存档，保留原连击显示和存档规则；统计刷新不查询法杖可施法状态。

6. 开发工具与流程
代码发布与工坊页面维护分离；发布严格按 prepare → commit → publish，冻结用户确认的对外说明和完整 commit 正文，使用独立 checkout。
新增确认标记、冻结哈希、恢复与发布范围回归测试；GitHub 认证可使用已有 gh 或 Git Credential Manager 凭据，仅在进程环境传递。
源码导出包含 AGENTS.md，排除 .log 及 stdout／stderr 临时输出；新增本地 OpenAI API 生图规范，要求保存源图与用量。新增图像流程素材及测试资料供溯源。
AGENTS.md 说明六类本地子智能体分工与成本约定；.codex 本机角色配置不在公共源码导出范围内，不改变游戏设置。
