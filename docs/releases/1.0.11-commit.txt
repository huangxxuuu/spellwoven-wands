Release v1.0.11

以最近成功正式版 1.0.10 的冻结包与回执为基线。2026-11-22 用户确认天气风向标为唯一对外条目并要求直接发布。

游戏改动
- 天气风向标被命中或定时触发、或以保存载荷释放时，以触发坐标为原生旋风的游荡目标。载体和原生旋风在释放点停止飞行，随后进入原生游荡行为。
- 直接施放继续按瞄准距离和寿命修饰计算飞行。
- 更新中英文游戏内简述和详细说明，以及下载包所附法术参数表的对应行。资料站图鉴由发布构建从同一组法术说明生成。

验证
- 新增触发回归覆盖命中、计时及保存载荷，检查载体与原生旋风停止，以及交给原生游荡行为的目标坐标。
- 定向通过 test_executor.lua、test_projectile_triggers.lua、test_engraved_spells.lua。264 个 Mod Lua 文件语法通过。日志为 test_reports/lua-tests-_qz1buql/output.log。
- 首次准备因 Windows 子进程继承的 Git 配置缺少空值而停在 Python 检查。仅在本次进程中移除与发布无关的配置后，发布流程测试 4 项全部通过。保留未冻结现场并用原基线重建干净的独立 checkout，继续同版本正式流程。
- 正式全量检查随发布脚本执行。客户端和专服实机未测。
