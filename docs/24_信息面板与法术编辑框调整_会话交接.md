# 信息面板与法术编辑框调整：会话交接

日期：2026-11-07。

## 用户确认的方向与当前实现

### 信息面板左上角

- 法术卡、法杖的信息面板不再额外叠加原版物品栏格子背景。
- 法术卡保持原有物品图标，尺寸由 40×40 放大为 50×50；文字起点为 x=62。
- 法杖改用实际地面外观，让杖身长度更直观。使用 `UIAnim` 和 `nw/visual.apply(..., "ground")`，隐藏 `contact_shadow`、`contact_grass`，保留杖头、杖身、杖尾组合。
- 三种长度统一使用 0.28 缩放，不按各自包围盒缩放到同样大小，以保留长度差异。
- 归档时当前代码使用 `GetVisualBB()` 将外观居中到左侧预留区；该实现已替代本聊天中最初的固定接地点定位。文字起点 x=84，头部最小高度 84。
- `hover_data.wand()` 通过 `wand_look` 传递外观编号；判断使用 `~=nil`，编号 0 也是有效外观。

涉及文件：

- `mod/scripts/widgets/nw_itemhint.lua`
- `mod/scripts/nw/hover_data.lua`

### 法术编辑框横向间距

- 保持格子和卡片尺寸，单独增加格子中心间距：76 → 82。
- 实际格子宽度仍为 74，因此格子之间空隙由 2 增加为 8（HUD 逻辑单位，屏幕像素随缩放变化）。
- `hud_layout.slot=76` 表示原有尺寸基准；新增 `slot_step=82` 表示中心间距。后续不要通过增大 `slot` 来调间距，否则会一起放大卡片。
- 外框宽度改为 `max(300, (count-1)*slot_step+slot+40)`。
- 原生容器初始布局、按容量重排、自定义只读行、鼠标格子命中范围同步使用新间距。
- `nw_slotrow` 新增可选第三参数 `step`，默认等于 `size`；信息面板内的小型已装法术行仍使用原有间距。
- 格子之间的空隙不应判定为选中卡片；屏幕边界限制继续根据新外框宽度计算。

涉及文件：

- `mod/scripts/nw/hud_layout.lua`
- `mod/scripts/nw/wand_container.lua`
- `mod/scripts/widgets/nw_slotrow.lua`
- `mod/scripts/widgets/nw_wandpanel.lua`
- `tests/test_hud_position.lua`（使用新中心间距并检查空隙命中）
