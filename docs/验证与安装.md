# 验证与安装

普通任务先按[开发导航](开发导航.md)运行定向检查。以下命令在项目根目录 PowerShell 中执行，使用已有 `.venv/Scripts/python.exe`；没有环境时再创建 `.venv` 并安装 `tools/requirements-dev.txt`。

## 离线检查

```powershell
# 定向 Lua（每次仍检查全部 Mod Lua 语法）；不传文件则全跑
.venv/Scripts/python.exe tools/run_tests.py tests/test_modifier_scope.lua tests/test_base_damage.lua
# 定向 Python
.venv/Scripts/python.exe tools/run_python_tests.py -p test_wand_container_native.py
# 其他非交互式 Python 检查，脚本参数继续跟在脚本名之后
.venv/Scripts/python.exe tools/quiet_check.py tools/check_localization.py
# 当前法术参数/人工场景按需定位，不需要通读全部表格
```

Lua 使用 Lupa 的 Lua 5.1 runtime。当前人工验收入口为[测试指南](11_法术卡测试指南.md)，早期单击施法等记录属于历史，不作为当前玩法规则。

三种入口默认只输出末尾总结，正常测试的 `print`、Lua/C层和继承输出的子进程日志均留在 `test_reports/` 的唯一日志，不回显全部。失败保留用例/阶段、断言或 traceback 摘要与必要上下文；超长诊断会注明省略，完整日志不截断，退出码仍为非零。Python 总结还列出跳过、预期失败与意外成功；零测试匹配视为错误。

需要详细排查时才加 `--verbose`：Lua/Python 测试入口可直接添加；通用包装写作 `tools/quiet_check.py --verbose tools/check_localization.py`。日志路径出现在末尾总结中，优先按错误关键词/范围读取，避免重新把整份日志送入对话。通用包装只用于非交互式检查；安装、专服、交互授权与发布操作仍使用各自入口，不用静默包装隐藏过程。

## 资料站

```powershell
.venv/Scripts/python.exe site/build_catalog.py --pages
.venv/Scripts/python.exe tools/quiet_check.py tools/check_localization.py
.venv/Scripts/python.exe tools/quiet_check.py tools/check_site_links.py --directory site/public
.venv/Scripts/python.exe -m http.server 8765 --bind 127.0.0.1 --directory site/public
```

页面源在 `site/dist/`；`site/public/` 是生成目录。普通本地构建不会部署。新增文本保留格式占位符，游戏词条和网页正文各自维护翻译。

## 资源与安装

先按[有效资源索引](art/05_资源索引.md)选择构建器。重建游戏动画/贴图需要本机 Don't Starve Mod Tools；已有编译资源随 `mod/` 提供。仅修改源码时不要无理由重建全部素材。

`.venv/Scripts/python.exe tools/install_mod.py` 同步当前 `mod/` 到本地开发 Mod 并逐文件校验；游戏运行期间安装器拒绝覆盖。安装后完全退出并重新启动游戏和世界。运行安装须属于用户任务授权范围；离线检查本身不要求安装。

工作区还有其他未验收改动时，可重复传入 `--file`，仅同步本次涉及的 Mod 相对路径，例如 `.venv/Scripts/python.exe tools/install_mod.py --file anim/nw_end_beam.zip --file scripts/nw/beam_visual.lua`。定向模式仍检查目标归属、游戏进程、选中动画包和复制后哈希；只校验选中文件，不删除退役资源。默认全量模式保持不变。

## 游戏验证

独立专服脚本为 `tools/smoke_server.py`，先查看 `--help`，按模块选择 `--balance`、`--dark-fog`、`--crafting` 等专项。脚本会启动专服、写测试目录/存档和日志；执行前确认测试范围和现有游戏状态。专项测试目录不等于已更新日常游玩的 Mod。

自动检查/无图形专服仅证明各自覆盖路径。远端客户端、进出洞穴、手柄、HUD 缩放和美术表现的实机结果单独记录，未执行时不宣称已通过。

正式发布另读[发布流程](发布流程.txt)，不因离线测试通过自动发布。
