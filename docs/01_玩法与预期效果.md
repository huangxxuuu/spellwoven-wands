# 饥荒联机版法杖 Mod 玩法与预期效果

日期：2026 年 10 月 28 日。状态：设计提案，尚未开发。暂名：织法之杖。

开发细节见 [开发执行规格](04_开发执行规格.md)，抽牌与外观语义见 [施法规则与运行时外观规格](03_施法规则与运行时外观规格.md)。本文中的建议值由执行规格补足，仍需游戏实测调参。

目标是在饥荒联机版中实现 Noita 风格的随机法杖与法术编排：探索获得不同属性的法杖，收集法术卡，在工作台上排列组合，与队友一起使用自己设计的武器。以下数量、数值、配方与规则均为本 Mod 的建议设计，不是 Noita 原版数值，也不是已实现功能。

## 玩家最终能体验什么

玩家制作一把基础法杖和奥术工作台，取得火花弹；随后通过战斗、探索和制作获得法杖胚与法术卡。法杖胚在服务器首次开启时生成固定属性，不能通过反复丢弃或重新装备刷新。法术卡可以交换给队友，也可以装入不同法杖。

在工作台附近打开编辑面板，上方显示法杖参数，下方显示有顺序的法术槽和玩家携带的卡片。点击或拖动卡片调整组合，确认后服务器一次性保存。面板显示预计每次施法的耗蓝、施法间隔及牌组循环时间；随机法杖只显示区间与可能组合，不伪装成精确预测。

装备法杖后向鼠标位置施法，支持对空地发射。按住施法键可以在服务器允许的频率下连续射击。HUD 显示法力、当前槽位与回充状态；其他玩家能看到法杖外观、发射方向、主要弹道和命中特效。普通攻击和施法输入应分开，避免拾取、检查和战斗操作冲突；具体键位由原型验证后确定并提供设置。

## 随机法杖

不是制作六件属性固定的武器，而是六类属性生成倾向，每类均能生成大量不同个体。外观统一采用可组合的杖头、杖身、杖尾；类型不锁定整根外观。统一用物品实例保存属性。

| 法杖类型 | 主要倾向 | 适合玩法 |
| --- | --- | --- |
| 枝芽杖 | 入门、低耗、稳定 | 单发火花与探路 |
| 速射杖 | 短施法间隔、小法力池 | 持续弹幕 |
| 储能杖 | 高法力上限、慢回复 | 高耗蓝爆发 |
| 复苏杖 | 快回复、中等容量 | 长时间战斗 |
| 编织杖 | 多格子、顺序施法 | 复杂组合 |
| 混沌杖 | 容易乱序、散射大、同阶预算补偿 | 不稳定多弹齐射 |

| 属性 | 含义 | 首版建议范围 |
| --- | --- | --- |
| 容量 | 可安装卡片的槽位数 | 2—12 格 |
| 法力上限 | 瞬时爆发预算 | 80—600 |
| 法力回复 | 每游戏秒恢复的法力 | 8—80 |
| 施法延迟 | 相邻施法组之间的等待 | 0.20—1.20 秒 |
| 回充时间 | 一轮牌组结束后的等待 | 0.60—3.50 秒 |
| 每次抽取数 | 一次施法由法杖提供的基础抽取次数，法术可以追加抽取 | 1—3 |
| 散射角 | 相对瞄准方向的随机偏角 | 0—15 度 |
| 乱序 | 每轮是否洗牌 | 是／否 |
| 固有法术 | 不占槽的固定修饰效果 | 稀有法杖最多 1 个 |

划分普通、精良、稀有、史诗四阶。生成器采用阶级预算和类型权重：容量大、延迟短、回复快、非乱序都占预算，不允许每项属性独立抽到最大优势。稀有法杖更有组合潜力，但不会保证所有属性都优于低阶法杖。

固有法术首版只允许加速、精准、弱追踪等白名单效果，作为“始终施放”每次执行，正耗蓝免除且不提供额外抽取；不允许固有触发器产生循环。入门法杖固定为非乱序并附火花弹，避免新玩家拿到无法使用的组合。

## 三段式法杖外观

法杖由杖头、杖身、杖尾三部分拼成，每部分提供多套原创贴图，使用统一连接点跨类型组合。先生成属性，再选择能表达这些属性的部件，最后随机选择材质与装饰。自由组合指部件可以互相搭配；表达属性的关键形状仍受约束，避免造型误导玩家。首版不额外引入玩家拆装外观部件的制作系统。

| 可见特征 | 对应属性 | 设计规则 |
| --- | --- | --- |
| 杖头中央是否有水晶 | 是否乱序 | 非乱序有明显中央水晶；乱序使用空心、木结或金属核心，不使用相似的中央晶体 |
| 杖头发射尖端数 | 法杖基础每次抽取数 | 1／2／3 个朝外尖端对应基础 1／2／3 发；水晶是独立的视觉标记，不计入尖端数 |
| 杖身长度 | 格子容量 | 2—4 格为短身，5—8 格为中身，9—12 格为长身；在完整属性面板读取精确格数 |
| 杖身储能环或嵌条数量 | 法力上限 | 80—199、200—399、400—600 分为少、中、多三档装饰 |
| 杖尾导流纹密度 | 法力回复 | 8—24、25—49、50—80 分为低、中、高三档；不用每帧闪烁表达回复速度 |

上述是本 Mod 的视觉约定，不声称完全等同于 Noita。尖端表示法杖自身属性，安装散弹或多重施法卡不会改变杖头；外观也不随临时耗蓝变化。颜色主要表达材质与风格，不单独承担属性识别，避免色觉差异影响判断。施法延迟、回充、散射和固有效果首版主要通过面板显示，不强行把所有参数塞进造型。

例如一根 10 格、非乱序、基础双发、高回复法杖，会呈现“有中央水晶的双尖杖头 + 长杖身 + 密导流纹杖尾”；一根 3 格、乱序、基础单发法杖，则是“无中央水晶的单尖杖头 + 短杖身”，其杖尾再按回复属性选取。相同属性仍可获得不同材质和纹样的外观。

初始素材预算建议为：杖头 6 种语义结构（水晶有无 × 1／2／3 尖端），每种 2 个造型；杖身 3 种长度，每种 2 个材质样式；杖尾 3 种回复档，每种 2 个造型。基础共 24 个部件设计，可产生 12 × 6 × 6 = 432 种组合，储能装饰另作覆盖层。432 是可组合的外观数量，不代表要预生成 432 张完整图片；采用独立动画部件运行时组合。长短杖身配置对应动画布局与连接点。同一组固定属性只能使用其中符合条件的子集。最终素材量由打包原型确认。

地面、手持、库存图标与检查预览使用同一组合信息。长杖不增加攻击距离或碰撞体积；库存图标保持统一缩放，避免把所有长度强制铺满相同尺寸而失去长短差异。小图标优先保留水晶、尖端和长短，精细纹样在检查预览中辨认。

## 首版法术范围

首版目标为 24 种，覆盖子弹、弹道、特殊效果和组合控制。名称和视觉为原创表达，机制参考 Noita，不提取其美术或声音。

| 类别 | 法术 | 预期效果 |
| --- | --- | --- |
| 子弹 | 火花弹 | 低耗、直线、基础单体伤害 |
| 子弹 | 魔法箭 | 较快、射程较远 |
| 子弹 | 散弹 | 一张卡生成三颗弱弹 |
| 子弹 | 重型能量球 | 慢速、高伤害 |
| 子弹 | 火焰弹 | 命中造成伤害与灼烧效果 |
| 子弹 | 冰霜弹 | 命中积累冰冻效果，遵守目标抗性 |
| 弹道修饰 | 加速 | 提高后续弹速 |
| 弹道修饰 | 减速 | 降低弹速并延长存在时间，无寿命上限 |
| 弹道修饰 | 正弦轨迹 | 沿发射方向左右摆动 |
| 弹道修饰 | 螺旋轨迹 | 围绕前进中心线旋转 |
| 弹道修饰 | 追踪 | 有限转向速度地追踪合法敌人 |
| 弹道修饰 | 弹跳 | 在可识别障碍表面反射，最多两次 |
| 特殊修饰 | 穿透 | 最多穿过三个目标，同一目标单弹只结算一次 |
| 特殊修饰 | 爆炸 | 命中产生小范围伤害 |
| 特殊修饰 | 连锁电弧 | 命中后向附近最多两个新敌人跳跃 |
| 特殊修饰 | 击退 | 对支持击退的目标施加位移效果 |
| 特殊修饰 | 吸血 | 按实际有效伤害小比例治疗施法者，设每秒上限 |
| 特殊修饰 | 照明 | 弹体及落点产生短暂光源 |
| 组合 | 双重施法 | 同组读取后续两个施法分支 |
| 组合 | 三重施法 | 同组读取后续三个施法分支 |
| 组合 | 命中触发弹 | 命中时释放后续一个子分支 |
| 组合 | 定时触发弹 | 到达指定寿命时释放后续一个子分支 |
| 参数修饰 | 伤害强化 | 提高伤害，同时增加耗蓝 |
| 参数修饰 | 精准 | 减少散射 |

弹跳先支持明确的墙体及阻挡物碰撞，海岸和复杂地形边缘需原型验证。无法识别可靠法线时让弹体消失，避免卡住或穿过地图。爆炸、火焰默认不毁建筑、不点燃营地；真实点火可作为服务器危险模式选项。冰冻与击退不保证对 Boss 生效。

## 组合与施法规则

采用 Noita 风格的牌库、手牌、弃牌堆与施法块机制，支持普通法术回绕。非乱序按槽位顺序装填，乱序由服务器洗牌。普通子弹结束一次抽取；修饰卡修改当前施法块并追加一次抽取；双重／三重施法分别追加两次／三次抽取。修饰对同一施法块的所有投射物生效，不能只按相邻槽位解释。触发载体与载荷分别处于父、子施法块。具体规则和示例以《施法规则与运行时外观规格》为准。

示例一：`追踪 → 火花弹`，每轮发射一颗追踪火花弹。

示例二：`伤害强化 → 双重施法 → 魔法箭 → 魔法箭` 和 `双重施法 → 伤害强化 → 魔法箭 → 魔法箭` 均发出两颗强化箭，因为修饰与两颗箭位于同一施法块。

示例三：`命中触发弹 → 双重施法 → 火焰弹 → 冰霜弹`，先射出载体，命中后同时释放火焰与冰霜分支。触发器只执行一次，载体因超距消失不算命中。

在预载阶段逐卡检查并扣蓝；耗蓝不足的卡直接进入弃牌堆，不消耗本次抽取名额，继续检查后续卡。触发载荷也在发射载体前预载并支付其成功执行卡片的费用，实际触发时不再次扣费。单卡费用超过法力上限仅提示，不阻塞其余法术。空槽忽略，空杖允许保存。尾部修饰、多重或触发卡可能通过回绕找到弃牌堆中的卡，不再以“尾部结构不完整”为由禁止保存。

回绕只由法术提供的额外抽取触发：牌库耗尽且弃牌堆有卡时，回收弃牌堆继续抽取；当前施法手牌不参与回收。发生普通回绕后，本次施法结束进入回充。法杖自身的基础多发不会单独触发回绕。例：`火花弹 → 双重施法 → 魔法箭`，基础单发时先射火花，第二次射魔法箭并回绕复用已弃置的火花，然后回充。

有效施法间隔和整杖充能均可降到 0 秒，实际施放仍受原版攻击动作、角色战斗冷却和法术专属冷却约束；牌组结束时同时满足本次施法延迟和回充等待，即取两者最大值。切换装备、丢弃、重新拾取不能跳过冷却。首版支持普通法术回绕，不包含魔杖刷新、高级复制法术和无限递归；因此不宣称完整复刻 Noita 的全部高级机制。

## 生存获取与平衡

工作台建议使用木板、金块、紫宝石，具体配方实测后确定。基础弹可制作；弹道卡由精英敌人或探索奖励取得；触发器和高级特殊卡主要来自洞穴与 Boss 奖励。掉落加入独立奖励逻辑，不替换原有战利品。提供稀缺卡的高成本保底合成，避免纯随机阻塞玩法。

老存档可通过工作台、敌人掉落和法杖胚获取全部核心内容，无需重开世界。首版不依赖新增地图地标。法杖不设耐久，法力是主要战斗限制；高级卡和高阶胚的获取成本承担成长门槛。默认战斗内外均回复法力，离线不额外回蓝。

平衡目标是：入门法杖提供安全距离但持续伤害受限，高阶组合提供控制和短期爆发，不能无成本替代所有近战武器。数值需同时测单体、群体、Boss 与多人叠加效果，再决定伤害、耗蓝与掉率。

## 联机与交付边界

采用所有客户端都需安装的服务端 Mod，覆盖玩家建房、独立专服，以及地面与洞穴分片。服务器决定随机属性、法力、施法顺序、命中、伤害和掉落；客户端负责操作界面与表现。默认 PvE 关闭玩家间伤害；PvP 配置必须同时约束投射物、爆炸、电弧与持续效果。队友召唤物和随从也应进入友方过滤。

首版包含原创法杖外观、法术图标、编辑面板、主要特效、中文说明、服务器配置和存档支持。首个技术原型只交付一把法杖和三种法术用于验证；它不等于完整首版。

暂不包含 Noita 的像素物理、液体模拟、可破坏地形、完整法术库、无限分裂弹幕和自动生成地下圣山。键鼠作为首版验收输入；手柄编辑界面作为后续扩展。
