织法之杖：你的下一发法术，由你编织


把「追踪」放在火花前，让它拐弯追敌；把旋斧藏进碰撞载荷，让一支魔法箭把近战送到远处。打完怪，换几张卡，还能采收、海钓，或给营地奏一小段旋律。

受《Noita》启发，《织法之杖》将法杖编排玩法带进《饥荒联机版》：收集法杖与法术卡，按顺序排列，组合自己的攻击、工具和乐句。

1. 换几张卡，下一发就是另一种法术



  • 追踪 → 火花弹：让直线飞行的小火花转向目标。
  • 双重施法 → 火花弹 → 魔法箭：一次出手，释放两种法术。
  • 三叉齐射：将一组法术分向发射；再试着加入穿透、弹跳或环绕。

法杖的槽位、法力储量、回蓝、施咒间歇与回充时长都会影响手感。非乱序杖按卡序施放；乱序杖会洗牌。好卡组也需要一根合适的杖。



2. 把下一组法术，藏进命中与计时之后


魔法箭·碰撞 → 旋斧攻击，箭命中后在远处释放旋斧；换成定时载荷，则改变释放时机。同一套搭配，触发方式不同，用法也不同。
「爆炸」是命中修饰卡，放在投射物前，让它击中时炸开。也可以布置近感晶雷、休眠晶体和空心载荷卵，把法术留在场上等待触发。



3. 熟悉的武器，也能刻成法术


在武器刻印台，用空白卡和配方指定的武器、工具及材料制作刻印法术。长矛、斧子、玻璃刀，都可以换一种方式出手。
暗影收割者还能沿途采收草丛与树枝，近处收获在条件允许时收入背包。换一套卡，战斗法杖也能成为干活帮手。



4. 带着法杖去海钓


把鱼食抛向海面诱鱼，再用海钓竿刻印投出鱼钩，将钩中的海鱼或漂浮物朝施法者方向送往附近的岸或船。
也有适用于池塘的淡水钓竿、在耕地翻土的园艺锄。工具法术保留各自用途，出门前按目的地搭配。



5. 让星光跟着你走


唤星、唤月法杖刻印可以生成原版矮星或极光。搭配移动、追踪与目标选择卡，让星体随人物移动。


加入弹体巨化，星体的外观与照明、温度、理智作用范围也会扩大。巨化还能改变适用法术的外观与作用范围，不直接提高伤害数值；星体法术仍保留专属冷却下限。



6. 收集、编排，再换一套



  1. 拿起入门杖。默认首次进入世界会获得已装火花弹的两槽法杖。装备后右键施法，站定后长按右键可连续施放。
  2. 建造奥术台。靠近炼金引擎，搜索「奥术台」。配方：木板×2、石砖×2、金块×4、紫宝石×2。
  3. 开始换卡。靠近奥术台并装备法杖，点击或拖动卡牌编辑。先试「伤害强化 → 火花弹」，再逐步增加新卡。

三座设施各有分工：

  • 奥术台：研磨宝石、制作法杖与卡牌、编辑法杖。
  • 武器刻印台：将配方中的武器与工具刻成法术卡。
  • 奥术分解炉：回收附近地上的废卡、牌堆和法杖，获得奥术粉尘。启动前先收好要保留的物品。


从左到右：奥术台、武器刻印台、奥术分解炉。

卡牌来自制作、刻印、生物掉落和首领战利品，部分卡只能从掉落中获得。法杖拥有不同稀有度与随机属性；散卡可叠成最多25 张的牌堆，法杖还可以用羽毛笔改名。
想比较伤害，可在科学机器旁用草×3、木板×1制作法术测试拳击袋，连续命中会累计显示伤害。



7. 法杖也可以是乐器


把陶笛、弦琴音符排进法杖，为营地演奏自己的乐句。两种乐器基础音覆盖 C、D、E、F、G、A、B；升降半音和八度卡可以改变音高。
加速、减速卡分别选择半拍、两拍的音符采样，不会自动同步连续施法的节拍。实际音符间隔仍受法杖属性、施法动作和手动换杖影响。
这次的实机演示，用弦琴卡组演奏了《深海少女》的一小段：旋律来自卡牌的排列，声音来自游戏内施法。
