## 已确认的设计

| 项目 | 决定 |
| --- | --- |
| 主类与轮廓 | 基础法术为切角矩形 R；法术修饰为上下尖的竖向六角形 H；施法控制为顶部中央宽凹口矩形 N。每张卡只有一个主类 |
| 标签 | 用于解释形态、机制、用途和跨主类筛选，不增加边框类型；物品栏卡面不堆标签文字 |
| 信息面板 | 卡名 → 主类及重点 2–3 个标签 → 一句话作用 → 作用范围或依赖 → 核心参数 → 详细规则；收藏册可展示完整信息 |
| 边框与纸底 | 选择「保留绘图空间」；统一浅暖灰纸底，极轻的上亮下暗渐变；纸底本身不透明 |
| 主图 | 以一个简单明确的主体表达作用；投射物主要用实际弹丸或载体；缩小后仍能认出大形 |
| 机制角标 | 右下角轻压边框，大部分在卡内；顶部居中留给原生数量。普通卡不留空徽章底座 |
| 角标语义 | 自带载荷的基础载体用碰撞、定时或被击破载荷标识；独立控制卡由主图表达，普通命中附效不自动加角标 |
| 材质方向 | 以 A 为基础，向精制、完整、饱满、有魔力的手绘卡纸深化；避免古旧易碎的主要印象 |
| 地面姿态 | 纸牌平躺，从下向上叠高；顶牌复用真实单张卡面，主图与边框共同接受透视 |
| 底堆变化 | 内层 R/N 合并按 R 处理，另有 H；两张底牌按顺序有 RR、HR、RH、HH，与三种真实顶牌形成十二组合 |
| 六角缺角 | 中夹 H 形成有下层纸面承托的暗凹槽；底层 H 的缺角处露出地面阴影；双 H 各自收窄，不能用矩形侧墙加三角装饰代替 |

分类看玩家实际使用职责，不直接沿用内部 `kind`。自带碰撞或定时载荷的投射物仍属基础法术；独立附加载荷机制、多重抽取及输出复制属于施法控制。治疗、音乐、采集、火焰等不新增主类。完整边界和像素起点见设计规范第 2–5 节。

卡堆顶牌按容器格子顺序取第一个非空卡，后续两张按真实顺序自然遮挡，不从深处挑选不同类别作展示。表层两张底牌中 H 的数量不代表全堆构成；完整统计应在信息面板体现。玩家取牌不因此改成只能取顶牌。厚度建议继续按 2–3、4–6、7–25 张分档并收敛增长，一张时恢复单卡。

## 必须保留的修订边界

1. 用户最初选的是 A 墨线羊皮纸，B 古籍铜角与 C 荆棘刻纹保留作历史备选。
2. 用户要求删除的是左上、右下的**内侧纸面卷角及其翻折阴影**，当时并未要求削薄或压平整个边框。保留框宽、双线和轮廓；错误的整体扁平化版本已废弃。之后用户另行授权调整配色和材质，不能误把早期局部修改限制理解成永远不能改色。
3. 魔力感优先来自主图的体积、明暗、亮核、晶面、方向或重复。边框使用深墨褐与克制灰金细边，不把所有卡做成大泛光、满底魔法阵、宝石框或金属盒。
4. 六角夹层缺角处有真实空间。RHR 的凹槽不能贯穿下方 R；RRH/RHH 不应补出水平矩形底脚。六角形前尖只是同一张纸的可见部分，不能额外外移或放大成贴上的三角。
5. 顶牌以下保留各自轮廓内的完整空白纸面，交给顶牌自然遮挡；不能预先减掉统一顶牌遮罩，否则 H 顶牌下的 R 露角、N 凹口里的下层纸面会缺失。
6. 纸层存在的位置保持接触，不以爆炸分层、悬空或扇开强行展示所有卡形。几何参考约束纸在哪里，美术图负责材质与阴影；生成图仍须逐项复核。
