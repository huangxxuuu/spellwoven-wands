# 宣传图规范

适用场景：工坊展示图、封面、宣传插画、场景截图式创作和宣传用单物件海报。更新：2026-11-09。

生图前先完整阅读[共同画风规范](../26_饥荒原版画风与生图基础规范.md)与本文。工坊“图标”属于宣传图；物品栏“图标”属于[游戏内物品栏贴图](03_游戏内物品栏贴图规范.md)。

## 构图与形象

先明确画幅、主要焦点、次要焦点及观看尺寸。物件可自然裁切、错开和遮挡，但关键身份特征须可辨；已确认法杖比例、卡牌轮廓和颜色继续保留。视角按叙事与构图选择，物件共享可信的空间与光线方向。

画面可以包含环境、人物、桌面、前后景。边框、文字、纸带、符文、光效等仅按本次要求使用；不自动继承上一张图的玫瑰边框、泛黄纸底或装饰元素。

## 线条 色块与纹理

线条强调疏密和主次：重要外缘与遮挡接缝较重，内部结构较轻，细节集中在焦点与必要的材质位置。背景线条可以更轻、更疏或逐渐融入色面，不将每个物件描成同样粗黑的独立小图标。

以大色块、少数亮暗层次和手绘高光塑造体积。可使用柔和环境色、雾层和局部光线，但主体形状保持清楚。鲜艳色用于视觉重点，整体色调由主题决定。

木材、玻璃、金属、纸张各有自己的笔触。局部暗面允许密排线；主图、纸面和亮面保留干净色块。避免全幅噪点、平均划痕和统一做旧。

## 输出与验收

- 完整场景通常交付不透明背景；独立宣传元素是否透明按任务决定。
- 源图比例与构图匹配目标展示位，不把所有宣传图固定成正方形。工坊方形展示图按实际需求使用1:1。
- 检查完整尺寸的形象、透视与材质，再检查目标缩略尺寸的焦点、主次和轮廓。
- 光影与物件接触一致，遮挡不破坏关键符号，背景细节不抢主体。
- 保存实际提交的完整Prompt、参考图角色与最终图。宣传源图不会自动成为建筑或物品栏可用资源；相应输出需另按对应规范制作。
