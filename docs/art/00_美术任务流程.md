# 图片生成和改图前必读

适用于主代理和受委派代理，跨会话仍执行。用户最新明确要求优先。

1. 每次新的美术任务，在编写或提交生图Prompt之前，实际完整读取[共同画风规范](../26_饥荒原版画风与生图基础规范.md)和[基础提示词唯一正文](../DST生图基础提示词.txt)。不得凭旧Prompt、上次会话记忆或文件名跳过正文。
2. 明确类别，完整读取对应规范：[宣传图](01_宣传图规范.md)（工坊封面/展示图）、[游戏内建筑](02_游戏内建筑规范.md)（世界本体/动画）、[游戏内物品栏贴图](03_游戏内物品栏贴图规范.md)（物品栏/制作栏/容器栏/快捷栏及采用物品图像的UI）。同一物件多类别输出分别处理；其他用途选最近类别并补目标要求。
3. 每次新的生图任务完整读取[本地工具路由、调用与模型选择](04_本地生图工具调用与模型选择.md)，调用前落实其中要求。用户指定默认 `D:/Projects/AI/open_xiaoai/local-imagegen/imagegen.py`；仅用户明确指定内置插件或确认API额度耗尽时可切换，普通429、超时、Key/依赖等问题不算额度耗尽。完整判断和记录规则以04为准，此项目路由优先于通用技能默认建议，单次插件使用不改变长期默认。
4. 从[当前资源索引](05_资源索引.md)找到目标的有效源图、选择记录与构建入口，再实际查看目标资源、已确认设计及参考图。原版宣传图、世界贴图、物品栏图标职责分清；保留已确认卡牌轮廓、双线边框、身份符号/颜色、法杖比例与连接，不凭文件名评图。
5. 按基础风格段＋对应类别附加段＋本次主体/构图＋各参考职责＋避免项组合。生成后按类别与真实观看尺度验收，保存实际Prompt、项目内源图及用量记录并报告路径。源图、运行贴图与控件显示尺寸分别核对，以当前构建和控件为准。
6. 已有源图的构建/打包问题优先复用流水线；每次修订针对明确偏差，减少无目标多轮生成和重复评审，保留已正确的身份与布局。只修改授权资源和脚本，不自行改工坊元数据或发布；如实报告源图、编译、安装、实机各自验收边界。
7. 委派时交代类别与上述必读路径；跨会话重新读取。同任务中已完整阅读且未变更的规范无需每次调用重复读。原版观察、个案、完整命令及历史定价已转到按需reference，不因无关案例扩大必读范围，也不以历史Prompt替代有效规范。
