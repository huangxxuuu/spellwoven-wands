## 上一版工坊桌面图的修正方向

上一版可保留桌面近景、卡牌与法杖的主次、粉尘瓶直立与倾倒的状态，以及物件之间的自然遮挡。

需要降低全幅颗粒纸纹与统一暖褐色处理；减少卡面和书页不必要的裂纹、划痕及深重边缘；把外轮廓、内部结构与材质线分开处理。木桌可以有木纹，玻璃瓶侧重瓶形与反光，金属侧重亮条和接缝，宝石侧重大切面，纸面保留完整浅色区域。

玫瑰褐边框来自上一轮指定参考，可以作为那幅构图的选择，后续图片不自动继承。减少细节时也不要抹掉所有手绘笔触；原版锅、木材和暗面仍有明确的纹理与排线。

## 支撑规则的原始线条与色彩观察

| 线条用途 | 绘制方式 | 样本中的表现 |
| --- | --- | --- |
| 外轮廓 | 总体较重，粗细有变化，转折有尖收与少量破笔 | 木箱、锅、宝石的外沿 |
| 遮挡与接缝 | 重要部位可接近外轮廓粗度，局部黑块压住前后关系 | 锅盖与锅身、冰箱门框、叠层金属 |
| 内部结构 | 比外轮廓轻，数量有限，明确分瓣、拼板、关节和切面 | 南瓜分瓣、机器铆钉、宝石切面 |
| 材质笔触 | 更细、更疏，方向服从材质与体积 | 木纹、短划痕、皮膜细线 |
| 局部排线 | 按暗面需要聚集，允许局部密集，不平均铺满 | 锅身暗侧、宝石下缘、落地阴影 |

原版样本并非一律低饱和。金块和机器上的球体可用很鲜明的黄色；蓝宝石、紫宝石与红色杖头也有明确彩度。宣传截图中的橙色南瓜、浅黄头发和白色眼睛同样鲜明。

图片1和原版地面物件的外轮廓通常比宣传动画人物更有重量。
