$imageToolRoot = 'D:/Projects/AI/open_xiaoai/local-imagegen'

## 调用示例

先读取 [共同画风规范](../../../26_饥荒原版画风与生图基础规范.md)、[基础提示词](../../../DST生图基础提示词.txt)及对应类别规范。先将本次实际提示词保存为 UTF-8 文件，再调用 API。下例的 `assets_src/my_asset_v1` 为示例任务目录，调用前创建目录并准备 `prompt.txt` 与所需图片。

```powershell
# 不联网、不消耗额度的参数检查
& $imagePython $imageScript generate --prompt '检查调用入口' --model gpt-image-2.5-flare --dry-run

# 纯文本生成：探索新造型，不需要参考图
& $imagePython $imageScript generate --prompt-file './assets_src/my_asset_v1/prompt.txt' --model gpt-image-2.6-flare --size 1024x1024 --quality medium --background transparent --output './assets_src/my_asset_v1/source-01.png'

# 参考图编辑：先查看每张参考图，再按 prompt 中的图号顺序传入
& $imagePython $imageScript edit --prompt-file './assets_src/my_asset_v1/prompt.txt' --image './assets_src/my_asset_v1/geometry.png' --image './assets_src/my_asset_v1/palette.png' --image './assets_src/my_asset_v1/style.png' --model gpt-image-2.6-sunburst --size 1024x1024 --quality high --background transparent --output './assets_src/my_asset_v1/source-02.png'

# 蒙版：PNG、小于 4 MB、与第一张输入图尺寸一致；完全透明区域表示编辑区域
& $imagePython $imageScript edit --prompt-file './assets_src/my_asset_v1/prompt.txt' --image './assets_src/my_asset_v1/source-01.png' --mask './assets_src/my_asset_v1/mask.png' --model gpt-image-2.6-sunburst --background transparent --output './assets_src/my_asset_v1/source-03.png'

# 同一个 prompt 生成多个候选；不同 prompt 必须分别调用
& $imagePython $imageScript generate --prompt-file './assets_src/my_asset_v1/prompt.txt' --model gpt-image-2.6-flare --size 1024x1024 --quality medium --background transparent --n 3 --output-dir './assets_src/my_asset_v1/candidates'
```

尺寸按任务选择，1024×1024 只是示例；源图尺寸不等于游戏运行贴图尺寸。参考图编辑的每张输入须为非空 PNG/JPEG/WebP、小于 50 MB，当前脚本允许最多 16 张。参考图数量以身份、构图、材质等实际需要为准。

透明背景使用 PNG 或 WebP，JPEG 不支持透明。`--output` 仅用于单张且拒绝覆盖已有图片或记录；迭代请使用新文件名。多张用 `--output-dir`。总是指定本项目内输出位置，否则默认会保存到工具所在项目的 `outputs/`。

成功时 stdout 返回 JSON，包含图片绝对路径、记录文件路径和 `usage`；进度和错误在 stderr，失败退出码非零。单张记录为 `<图片名>.json`，批量记录为输出子目录内的 `request.json`。记录包含完整 prompt、参数、参考图路径、用量与请求 ID，不含 Key。默认网络超时 600 秒，可用 `--timeout 900` 调整；SDK 自动重试已关闭。


## 成本与实际基线

2.5/2.6 Sunburst 和 Flare 的普通调用单价为每百万 tokens：文本输入 5 美元、图片输入 8 美元、图片输出 30 美元。相同单价不等于相同每张费用；不同模型、尺寸和质量可能使用不同数量的 tokens。价格会变化，进行新预算承诺前重新核对官方价格。

2026-11-10 的奥术台实测：同一个 `B_round_3/workbench.prompt.txt`，三张参考图，每次一张，`gpt-image-2.5-flare / 1024x1024 / high / transparent`，三次均成功。

| 每次文本输入 | 每次图片输入 | 每次输出 | 每次合计 | 每次估算费用 | 平均耗时 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 769 | 4,563 | 1,756 | 7,088 tokens | $0.093029 | 29.45 秒 |

三次共 21,264 tokens，费用估算 $0.279087。100 美元约可支持 1,074 张相同条件图片，不代表已读取账户余额。详见[测试记录](../../../../assets_src/arcane_workbench_api_test_20261110/cost-report.json)和[白灰背景对比图](../../../../assets_src/arcane_workbench_api_test_20261110/comparison.png)。

纯文本生图没有参考图输入费用。若假设本例的文本与输出 token 数不变，单张约 $0.056525，100 美元约 1,769 张；这是推算，不是纯文本实测。已有角色、建筑需要保持造型时，不要只为省费而删除必要参考图。明确每张图的职责，减少无关图片更合适。
