# 0.22.0 人工测试清单

适用于「织法之杖 · 开发版」0.22.0。清单按目前能查到的日志和玩家反馈整理。没有实机反馈的项目标为待验，不能由此推断从来没人测过。方框用于记录本次结果。

## 准备（单人即可）

在测试世界启用 0.22.0，关闭创造制作。要使用下文的 `nw_*` 命令，在服务器 Mod 配置里打开「开发者选项」并重启世界。「开发加载自检」保持关闭。按 `~` 打开控制台并选“远程”。普通的 `c_spawn`、`c_give` 不需要开发者选项。

## 第一轮 · 新建筑和分解取消（约 15 分钟，优先做）

### □ 1. 正常建造、并排选台和地图图标

1. 找一块空地，执行以下两行。在炼金引擎旁从制作菜单放置奥术台和奥术分解炉，在炼金引擎旁预制武器刻印台，再走到没有工作站的空地部署。把两座制作台放到能站在中间分别点击的位置。
   ```lua
   c_spawn("researchlab2")
   c_give("boards",4); c_give("cutstone",6); c_give("goldnugget",4); c_give("purplegem",4); c_give("nw_dust",4)
   ```
2. 点击奥术台，找火花弹和长矛戳击；再点击刻印台做同样检查。**预期**：奥术台能做火花弹，刻印台能做长矛戳击。来回点击时，当前台子的图标、专属列表和可制作状态跟着切换。用搜索和已固定的快捷配方再试一次，走远后不能绕过工作站限制。
3. 在刻印台输入 `c_give("nw_blank"); c_give("spear",2); c_give("nightmarefuel")`，实际做一次长矛戳击。确认扣两把矛，获得一张正确的卡。
4. 在正常镜头距离绕三座建筑走一圈，再打开地图。检查放置预览与落地位置、脚边碰撞、刻印台的交叉武器和分解炉的悬晶是否清楚。制作栏与地图中应能区分两座新建筑。记录看不清的是哪个图标、什么缩放。

### □ 2. 准备一组能数清的回收物

1. 执行 `c_give("nw_spellcard",6)`。丢一张在炉旁，鼠标拿另一张右键地面卡，再拿第三张右键牌堆，组成 **3 张卡的牌堆**；关闭牌堆。另放 **2 张散卡**在炉旁，留 **1 张在背包**。
2. 执行 `nw_combo("arrow","frost")`，将试验杖丢在炉旁。用 `nw_card("heavy")` 领取重能量球，放在距炉心 **超过一块地皮边长**的位置。把范围内的物品稍微放散，便于看见每一次转化。
3. 此时本批应播报 **5 张法术卡、1 根法杖**。杖内的 2 张、包里的 1 张、范围外的 1 张均不计入。

### □ 3. 做三次启动，覆盖两个取消窗口

| 次数 | 怎么做 | 通过标准 |
|---|---|---|
| 第一次 | 悬停炉子看边界，右键后等光圈扫过第一件物品，立即移动 | 从手接触炉子时开始约 2 秒扩圈，先近后远亮轮廓。走开后轮廓清除，本批零消耗。 |
| 第二次 | 重启，等读出「5 张法术卡、1 根法杖」，在「开始分解」前走开 | 能看清数量，有约 1 秒反悔时间。地面物品完整，没有粉尘。 |
| 第三次 | 重启，等第一件闪光，立即走开，继续观察 3 秒 | 走开后不能再有新的转化。已产出的粉尘留在原处，其余物品仍可拾取，炉子恢复待机。高密度时以实际看到的已转化件数核对。 |

### □ 4. 整批完成、退卡和空炉

重新布置第 2 项的初始组合，清走上次留下的粉尘，再启动并站定到「分解完成」。**预期**：3 张牌堆的位置留下 3 粉尘，两张散卡各留 1 粉尘；这根测试杖在自己的位置留下 1 粉尘及原来的魔法箭、冰霜弹。合计 **6 粉尘、2 张退卡**。退卡不会被同一批再吃掉。背包卡和范围外重能量球仍在。把产物收好，空炉再启动一次，检索结束后应提示附近没有可分解物并停止。

观察白天和傍晚两种光照。尤其留意石炉是否抖动、青色轮廓是否盖住卡面、角色台词能否在下一句出现前读完。

## 第二轮 · 单人存档与此前扩充内容（可分开做）

| 待验 | 步骤 | 通过标准 |
|---|---|---|
| □ 旧世界和地下分片 | 用有旧奥术台和旧分解炉的**存档副本**升级，先不拆建筑。检查配方和炉体，再建刻印台。带一根已知槽序的法杖下洞、返回，正常退出重进。 | 原炉变为 B2；A3 在炼金引擎旁解锁后可在空地部署；武器配方只在刻印台可用。法杖槽序和外观保持，两座台重进后仍能用。没有合适旧档就标「未测」。 |
| □ HUD、悬停和拖放 | 用 `nw_hudkit()` 依次装备 2、7、12 格杖。在台旁拿着一张卡，移过背包和杖槽，再换卡；离开奥术台重试。右键长按边框移位，重启客户端。 | 三种宽度均能显示，持卡时详情不挡放卡；仅在奥术台附近能换卡。重启后保留窗口位置。 |
| □ 新法术的画面和声音 | 用 `nw_range()` 布靶，分别装备 `nw_combo("garden")`、`nw_combo("payload_egg","moon_fall")` 和 `nw_combo("double","vital_ring","vital_ring")`。再依次比较 `nw_combo("chord_d")`、`nw_combo("speed_up","chord_d")`、`nw_combo("speed_down","chord_d")`。 | 哨株在命中点萌芽开火；自己击碎卵后落石出现在卵处；半血友方靶留在双环内时每跳回 4。三个音高依次为原音、升一个半音、降一个半音。 |
| □ 近战工作和目标选择 | 朝树矿交界使用 `nw_combo("target_nature","edge_multitool_axe_pickaxe")`；用 `nw_combo("target_building","arrow_hit","edge_hammer")` 打可锤的测试建筑。另以敌对、友好、中立选择卡分别对猎狗、已招募猪人、未交战的普通生物试射。 | 自然目标在小范围内积累工作量；远程锤击发生在落点。观察目标筛选时使用新生物，避免前一次攻击引发仇恨后把中立目标当成敌对。 |
| □ 密集施法与实际帧率 | 先用 `nw_combo("spark")` 打靶作对照，再用 `nw_combo("repeat_3","trident_cast","spark","fire","frost")` 连续施法 30 秒。停止后再观察 10 秒，同时留意弹头、独立尾迹、角色移动。 | 记录卡顿发生在出手、命中还是特效消散；停止后特效应清理。若能稳定复现，记录人数、是否洞穴及「玩家子弹数量」设置。 |
| □ 获取节奏 | 正常游戏时记录有代表性的定向掉卡或 Boss 携卡，写出生物、是否掉杖、卡名和掉率倍率；要比对可查逐卡表。 | 本项评估玩家多久拿到想用的卡。稀有掉率和 0.01% 兜底已有规则测试，单次没掉不能判错，无需为验收反复刷怪。 |

**分解炉补测（单人可选）**：在同一个测试世界把牌堆装满 25 张，完成分解后应在牌堆位置得到 25 粉尘。另起一批，在仍有标记时正常退回主菜单，再进世界。分解不应自行续跑；仍存在的炉子可再次启动，地上没有永久轮廓。测试受击、退服或拆炉时，以实际保存或中断时已经转化的数量为准。

**开发者开关（最后做）**：关闭本世界「开发者选项」并重启，在远程控制台输入 `print(type(nw_help),type(nw_rollwand))`，应得到两个 `nil`。重新打开并重启后应得到两个 `function`，调用 `nw_help()` 能列出命令。

## 第三轮 · 有第二位玩家时再做

用普通加入者客户端操作一次，再由房主操作一次。没有第二位玩家可整组留空。

1. □ **同屏同步与抢拾**：甲启动炉子，乙观察扩圈、高亮，再在数量播报后捡起一张已标记的散卡，打开一个已标记的牌堆。预期乙保有散卡，打开的牌堆不被消耗，其余按批次结算；两人所见产物一致。
2. □ **并发与断线**：两炉范围重叠，两人同时启动，地上只放一堆已知张数的牌。总产物应恰好一堆的价值。另铺几张散卡，让操作炉子的加入者在首件分解后断开连接；房主检查剩余卡不再转化、无残留轮廓，且可重新启动炉子。
3. □ **受击打断**：让加入者操作炉子，在数量预告或分解中途被怪物击中并打断动作。确认角色已脱离操作后，其余物品全部保留。
4. □ **选台、换卡和 PvP**：两人分别点紧邻的不同制作台，各自菜单应独立。加入者在奥术台换卡、施法，房主核对实际命中和卡槽。用 `nw_combo("target_players_other","spark")` 在和平世界和开启 PvP 的测试世界分别打对方：前者不伤队友，后者命中时能扣血；`nw_combo("target_self","spark")` 检查显式自伤。使用无护甲、非无敌角色，以实际命中为准。

**反馈格式**：项目编号／通过、失败或未测／房主或加入者／如何触发／实际看到什么。分解数量异常时附「开始前物品、结束后剩余物、粉尘数量」；视觉问题附截图；崩溃附日志最后一段即可。
