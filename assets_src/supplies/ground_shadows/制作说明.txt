具体绘制
瓶底：较宽的接触墨块，左右疏密不对称，外围少量短线。
野兽核心：较窄的接触区，短线集中在底部尖角两侧。
霸主核心：底部黑块稍重，外围碎笔更宽，避免与主体轮廓分离。
卡牌：阴影沿前后纸角倾斜展开，密处压在后卡尖角下面，右侧较疏。
所有地影均使用尖收的填充笔形、间断细线与少量透明度变化，没有椭圆或模糊滤镜。
ground-shadow 是 SVG 第一层，物品主体绘制在其上；编译后合为一个 symbol。

构建与定位
源 SVG 从 128×128 / viewBox 0 0 64 64 改为 144×144 / viewBox -4 0 72 72。
每个 SVG 单位仍为 2 像素。横向各增加 8 像素，底部增加 16 像素，不缩放主体。
动画顶边仍为 -124，左右为 -72/+72，底边为 +20；边界包含新地影。
物品栏构建先移除 ground-shadow，再恢复原来的 128×128 画布，保持旧图标。
nw_materials.lua 移除了粉尘和两种核心的 DynamicShadow，避免叠出第二份椭圆阴影。
