画风必须保持本项目已确认的《饥荒》原版二维手绘风格：清楚剪影、有轻重层次的墨线、大色块和少数亮暗分面；干净纸面、稀疏材质笔触、克制的手绘高光。宣传场景靠遮挡、色面和局部光线产生空间。手绘黑色轮廓仍清楚，绝不改成写实电影布光、3D渲染、满幅颗粒、厚涂或复杂表面反射。

本次只做统一的氛围调光：
整体从明亮均匀的暖棕桌面变为晚间烛光下的奥术工作桌。环境明显更暗，主要阴影为深灰褐、暗紫、少量蓝灰。桌面背景、后方空桌、装饰边框和紫色桌布首先降亮，外围暗、中央制卡区域仍可读；相较原图整体感受暗约四分之一，最外缘可更深，但不应黑成一团。
保留画面原本各物体的固有色，不能给所有东西套同一种蓝色、绿色或灰色滤镜。木桌依然是木褐，书封依然深紫褐，纸依然暖象牙色，粉尘依然紫色，绿杖头、蓝宝石、鲜黄金块仍可一眼识别。降低环境的暖红和橙棕饱和度，把暖色留给烛火附近及少量金属受光面。

光源和重点：
1. 利用图1原有左上蜡烛作为小范围暖光源，保留明亮火苗，蜡烛周边、临近木面、金属边和玻璃朝光一侧有克制的琥珀色受光。光线向远处衰减。没有新增灯、窗口或照明道具。
2. 原有青蓝大晶石与绿色杖头保留利落的亮切面，可给极邻近区域一点很弱的冷色反光，但没有巨大光晕、烟雾、漂浮粒子或激光。不要让整个桌面像霓虹灯照射。
3. 三张主卡作为中央焦点：纸面从明亮米黄调为柔和的旧象牙色，降低眩亮感，但三张同步保持同一绘制清晰度、同类线宽和色面层次。火焰橙红、追踪箭头的粉红与蓝、冰晶的青蓝都保持清晰；不让中央符号淹没在阴影里，不给每张卡添加独立聚光灯。阴影只沿合理接触与背光面组织。
4. 右上立书封面变得更深沉，四个已确认浅奶油淡金字仍是可读的局部亮面。保持标题准确「织法／之杖」，沿用图1每个字的轮廓、卷钩、尖楔、宽捺、位置、字号、两行排列和透视，绝不能重设计字形或变成其他字。金护角与搭扣变成暗金基调加少量暖亮条，书架暗面加深但结构可读。
5. 前景法杖在阴影中仍有连贯轮廓，绿色晶石和少数金色接环高光构成次焦点。木杆下的细小离桌缝隙和落影保留，不能用压黑掩盖结构。蝙蝠翼、小卡堆与布的对比适当降低成为次要区域，但边缘和固有色仍辨得出。
6. 四周仅做轻微自然暗部收束，没有生硬椭圆暗角、浓黑边晕或明显渐变滤镜。局部柔和光色允许，但造型明暗仍以手绘色块为主。
