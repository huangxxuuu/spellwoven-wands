# 手持法杖 HUD 素材

`status_source.png` 由内置 imagegen 生成。统一提示：透明背景三列图标；饥荒手绘黑色粗线；低细节、24 像素可读；红色禁止符号、象牙白羽毛笔、浅金八角施法火花。无文字、无外框、无写实材质。

`tools/build_hud.py` 将三个图标裁切、缩到 64 像素图集单元。圆环是代码绘制的进度控件，61 帧由十二点钟开始顺时针填满。法力条是 Widget 矩形控件。

0.14.1 的窗口使用独立生成的 `frame_source.png`。提示以已确认效果图为参考：深棕旧木、哑光浅棕内缘、黑色手绘轮廓、四个切角、等厚四边、深棕底板、透明外部、无卷曲装饰／文字／白色条带。`tools/build_hud_frame.py` 裁切至 256×256 后导出九块；`nw_wandframe` 固定四角为 16 HUD 像素，并独立设置每块位置与大小。原版 dialogrect 的金线与白色边条不再参与显示。

`tools/check_hud_frame.py` 解码实际编译的 KTEX，按控件布局绘制 2、7、12 格预览，并检查全部 2～12 格的图块覆盖、拼缝和侧边颜色。这是运行素材的离线拼接图，不是生成式效果图或游戏截图。
