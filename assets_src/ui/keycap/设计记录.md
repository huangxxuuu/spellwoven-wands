# 键帽资源设计与构建

当前构建采用用户提供的 v5 提示词生成的 [keycaps_v5.png](v5/keycaps_v5.png)，提示词原文见 [prompt.txt](v5/prompt.txt)。键帽外部、顶面、前面与右侧面均透明，仅保留黑白黑轮廓；没有烘焙文字。旧几何填色稿 `keycap_atlas.png`、`compiled_preview.png` 保留为历史，已退出构建。

使用项目指定的本地 `D:/Projects/AI/open_xiaoai/local-imagegen/imagegen.py`，模型 `gpt-image-2.6-flare`、high、transparent、PNG。首稿 1536×1024；一次 2048×1024 宽度修正编辑另存为 `v5/keycaps_v5_widthfix.png`，未采用。两次原始 Prompt、参数、usage 分别在同名 `.png.json` 中；合计输入 4004、输出 2535、总计 6539 tokens，不推算价格。

两次生图的中号宽度均未达到目标比例。运行控件以 1 / 1.5 / 1.75 三档宽度显示：切片两端保持原比例，中心横向适配；原始生图保留不改。构建器从首稿三枚实际轮廓裁切，统一高度 128，左段 32、右段 48，中段为 84 / 120 / 189。图集为 512×512，九元素登记到 `mod/images/nw_keycap.xml` / `.tex`。裁切、哈希与各面透明抽检见 [build_report.json](v5/build_report.json)。

`widgets/nw_keyhint.lua` 先用原版 Text 的 `GetRegionSize` 测得当前语言、实际字体的键名宽度，加上顶面边缘留白，再选能容纳它的最窄一档；不按字符数或按键种类固定分档。超过最大档时只扩展中段，键名字号固定。键名采用游戏自带 DIALOGFONT，提升 Backspace 等长键名的可读性。仅鼠标旁施法提示使用键帽，设置页和录入提示为纯文字，鼠标继续用原版图标。

键名字色按用户要求采用原版鼠标强调色：从 `fonts/controllers.zip` 的右键 U+E101 实际纹理中筛选不透明米棕高亮像素，主色和中位数均为 RGB(206,162,115)，即 `#CEA273`。保留原生字体黑描边，深浅背景预览均已查看。此调色仅改 UI 常量，不改轮廓图、按键选择或输入逻辑。

项目根目录构建命令：`.venv/Scripts/python.exe tools/quiet_check.py tools/build_keycap.py`。三枚源图、运行图和编译后顶/前/右面中心的 alpha 均为 0；[编译预览](v5/compiled_preview.png) 显示深浅背景下的固定端部拼接。

预览命令：`.venv/Scripts/python.exe tools/quiet_check.py tools/preview_keycap.py`。输出 `test_reports/keycap/keycap_preview.png`，包含 K、F5、Tab、Space、退格/Backspace 和原版鼠标；另有双语纯文字设置页。预览运行真实 Lua 控件、解码编译纹理和原版英文字体/鼠标字形，中文采用带描边的替代字体；这不是实机截图，客户端视觉仍需验收。
