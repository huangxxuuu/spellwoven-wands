# 共享卡堆素材与运行时组合

2026-11-07，接入版本 0.25.15。替代 v3 中逐组合导出的198张整堆图片；旧目录保留作设计记录，不加入 Mod。

## 素材组成

- 3张单卡专用纸层：侧边约2.7px（256px画布），含浅纸芯及深色底沿，仅用于单张。
- 3张通用纸层：矩形 R、六边形 H、顶部凹口 N。上部根据前三个非空格子的真实类别叠放；一张卡仅使用一层，两张使用两层。
- 6张下部底堆：4–8张的无／有六边形两种；9张以上的无、一个、两个相邻、两个分隔四种。
- 3张接地阴影：按最底层真实轮廓选择，同一个牌堆只有一张接地阴影。
- 顶牌主图使用独立的既有卡面符号，替换共享动画中的 `face`。不为每张法术卡重绘底堆。

768px母版在 `master_768/`，256px运行时导出在 `runtime_256/`。共15张共享图，各导出两种尺寸。198种牌堆加3种单卡仍有201种排列，但每种排列仅存图片引用、位置和绘制顺序，不存整堆贴图。

## 运行时

`nw_card_piles.zip` 包含15张共享图和201段静态组合动画；`nw_card_faces_0..4.zip` 仅包含220个兼容卡面符号。它们用同一实体、同一 AnimState 绘制，无独立纸片实体或逐帧组合任务。

卡牌定位点为256px画布下的 `(128,136)`，对应最底层纸面中心。图片已经透视，使用 BillBoard 保留画面方向；改用 `LAYER_BACKGROUND` 和排序3，使人物覆盖地面卡牌，不再重复应用地面投影。

地面牌堆的 `_layers` 只同步第二、第三张的真实类别，以及第四张起的六边形数量类别（0／1／多个）。多六边形的相邻或分隔由服务器创建时选择，通过 `_separated` 同步并保存；增减卡牌、客户端刷新和读档不重新选择。真实容器内容及顺序不变。

底堆和上部各自沿真实轮廓绘制侧边。相邻模板中两个六边形共用横向偏移，中间没有矩形；分隔模板中两者之间有矩形层。纸层之间的遮挡由同一动画的顺序决定。

## 可复现构建与验证

```powershell
.venv/Scripts/python.exe tools/build_split_card_ground.py --art-only
.venv/Scripts/python.exe tools/build_split_card_ground.py
.venv/Scripts/python.exe tools/check_card_resources.py
```

第一条仅导出素材；第二条编译地面共享动画和卡面，不重建物品栏；完整 `tools/build_card_resources.py` 也已使用该共享构建流程。

`manifest.json` 保存素材名称、全部排列及位移。`index.html` 展示共享图片和组合预览。实际编译结果的解码预览为 `test_reports/card_resources_compiled.png`（仓库根目录下）；专项检查覆盖动画图集页数、所有卡面与排列引用、存档视觉选择、四档分界、真实格子顺序、叠牌及修复法杖入口共存。未运行完整游戏测试；走过卡牌、鼠标拾取和实际存读档需要手动确认。

## 单卡厚度调整

单卡专用纸层与卡堆纸层分离，单卡侧边由约1.3px加到约2.7px（母版取整后），卡堆仍为约1.3px，仅略提亮纸芯。所有堆叠位移、顶牌卡面及接地阴影保持不变；中厚档底堆由同样的薄纸层重建。实际编译预览现在包含三种单卡及九种卡堆。`test_reports/card_thickness_comparison.png` 为源码合成前后对比，各格左旧右新，下面为侧边放大。
