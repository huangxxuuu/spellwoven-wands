## 试画内容

- 边框色带加深为低饱和墨褐，保留原有宽度和双线层次。
- 去除明显裂纹、破口、污斑与密集排线；纸面完整干净，不恢复卷角。
- 使用窄幅灰金高光与少量短刻线表现精细加工，不增加大宝石或整圈泛光。
- 收藏册保留细节，物品栏简化刻线；地面保持薄纸、平放、向上叠高的关系。
- 中央保持留白，未添加法术主体。本轮没有改绘现有法术图标。

## 已保存的主图建议

- 火焰保留橙红外焰与集中亮核，冰霜保留青蓝与白色晶面，重弹保留深壳与紫色能量。
- 2026-11-07 用户补充：有对应原版武器或道具的卡原则上直接复用原版素材，只等比缩放与定位，在边框内尽量大；园艺锄等工具主图不再重绘。该规则优先于早期对工具形象进行精绘的建议。
- 用户随后明确三个例外：旋斧攻击 `whirl`、长矛戳击 `thrust`、玻璃刀砍 `slash` 各自单独绘制主图，以对应原版武器的可辨形象配合旋转、前刺、挥砍轨迹表达动作，整体仍完整位于框内。当前 64 张明确原版来源的公开卡中，61 张原版直用、3 张按此例外单绘；计数表示设计分工，不表示运行时已全部替换。
- 以完整大形、清楚明暗和局部亮点表现饱满与力量，把细碎纹理归并为大块层次。
- 修饰与控制优先表达方向、轨迹、分叉和重复；不要求所有法术都有强发光。
- 避免统一的大泛光、满底魔法阵或元素色边框；主图保持最高的颜色与亮度关注度。
- 后续放入火焰、冰霜、重弹、武器或工具四类主体，检查冷暖色、明暗和实体图形的兼容性。收藏册可增加精细刻线与微光，小图优先可读性。

## 检查与制作状态

已查看生成图，三类轮廓、深色带、完整卡纸与地面平放方向可辨。图片可解码，单张大图具有真实透明外部；其 alpha 范围为 0–255，纸面中心采样为 253。正式制作还需要统一纸面不透明度、处理透明色边并拆分边框与纸底。
