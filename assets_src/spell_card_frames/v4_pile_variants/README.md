# 卡堆多形态外观 v4

日期：2026-11-07。状态：保留的设计评审旧版，尚未替换运行时资源。

**已知问题：**v4 中 H 位于内层时，相对 R 缺少的角部空间与退进凹槽未正确表现，容易看成完整矩形侧墙外挂一个六角形前尖。旧图与记录保留不覆盖，不能作为夹层空位已精确绘制的依据；修正见 [v5 缺角与夹层凹槽](../v5_pile_recess/README.md)。RHR 应在上 R 悬边与下 R 承托纸面之间形成局部阴影凹槽，且不能穿过下方 R；RRH 的底部缺角处应露出悬边和地面暗影，不能补出矩形底座；RHH 两张底牌都应收窄。纸层仍需接触对齐，不做爆炸分层或扇开。

## 设计范围

顶牌复用实际单张卡牌的纸底、主图、边框和必要角标。新增美术重点为其下方的纸层，使用 [v3 精制魔法卡纸](../v3_refined_magic/README.md)的深墨褐边框和浅暖灰纸底。

底牌只分两种外形：R 为切角矩形，H 为竖向六角形。带顶部凹口的矩形在内部按 R 绘制，不单独增加底堆类型。真实顶牌仍保留 R、H、N 三种完整外形，其中 N 为顶部凹口矩形。

## 四种底堆与十二种组合

本轮对照图固定为“顶牌＋两张底牌”。组合从紧贴顶牌的下一张向下读取；HR 表示上层底牌为六角形、最下面一张为矩形。这样可以比较下方有 0、1、2 张六角形时的区别，一张六角形还分上、下两种位置。

| 底堆 | 六角底牌数量 | 预期轮廓 |
| --- | --- | --- |
| RR | 0 | 两层较平直的前侧纸边 |
| HR | 1，靠上 | 上层底牌的六角前尖，下层矩形形成较完整的底边 |
| RH | 1，靠下 | 矩形纸边在上，最下层六角前尖形成局部伸出 |
| HH | 2 | 两层相近的尖形前纸边 |

四种底堆分别与 R、H、N 顶牌组合，得到十二种组装预览。顶牌不需要跟着每种底堆重复绘制主图。完整组合表见 [variants.json](variants.json)。

## 叠放与遮挡

- 所有纸牌平躺、朝向一致、基本对齐，仅沿高度叠高；不靠扇开或大幅向后错位展示底牌。
- 保留细薄纸层的亮边和层间暗线，不能把侧面画成厚木板、金属盒或完整封闭的台座。
- 底堆保留完整的空白纸面，再由真实顶牌遮挡，不预先挖掉统一的顶面区域。
- H 顶牌盖在 R 底牌上时，矩形边角自然露出；N 顶牌的凹口区域自然显示其下方纸面。
- 顶面随堆高向上移动，底堆的接地位置和阴影保持稳定。

本次图中“有几张六角形”对应实际画出的两张底牌。正式卡堆超过三张时，可以优先表达靠近表层的两张真实形状，深层以纸边概括；不能为了显示深处的六角形而把它抽到表层。整堆的类别统计仍由信息面板提供。

## 资源与实现建议

组合逻辑为接地影 → 最下层 U2 → 紧贴顶牌 U1 → 实际顶面。可绘制 R/H 两种底牌薄层并组合，也可烘焙 RR、HR、RH、HH 四种底堆；本轮先用四种底堆比较外观。只有两张卡时仅显示一张底牌，剩一张则沿用单卡。

数量造成的薄、中、厚档与形状组合分开处理。先确定三层示意中的轮廓和层间关系，再扩展 2–3、4–6、7–25 张的厚度表现；本轮不把十二种组合再乘上所有数量逐一重画。

现有 [paper_edges 构建](../../../tools/build_art_assets.py)共用基准卡牌轮廓，并会减去顶面遮罩；这种做法无法直接保留 H 顶牌下方的矩形露角。正式接入需要调整底层生成与遮挡规则，并同步实际下层形状。当前只设计素材，没有修改构建、网络字段或游戏逻辑。
