## 本轮实际交付规格

- 3 张风格板：每张 **1448×1086，RGB**，包含三种主类轮廓及收藏册、物品栏、地面用法。
- 3 张基础法术单张样稿：每张 **1254×1254，RGBA**，外部有真实透明通道，中央暂时保留纸底，未绘制主图。
- 风格板中的物品栏与地面图目前是设计展示，尚未作为独立 64×64 / 地面动画素材导出。
- 单张样稿是“边框＋纸底”合成图，尚未拆为纯边框层与纸底层。
- 提示词请求了更大尺寸，但以上数值是工具实际返回并已核对的尺寸；没有把放大重采样称为新增高清细节。

### 原图检查与正式制作边界

已查看六张生成图，核对三类外轮廓、边缘风格和地面平放姿态。文件可解码，三张单图 alpha 范围均为 0–255、左上画布角为 0；纸面中心 alpha 为 253，仍需在正式制作时统一为不透明。部分透明外缘有少量杂色，正式导出时需要清理并在深浅背景下复核。

生成样稿尚未按游戏像素规格对齐；64 格包围盒 52×56、三个统一轮廓、指定渐变、顶部数量区和右下角标区仍是后续正式制作的核对项。本次 v2 只删除用户圈出的左上、右下两处内侧卷角、翻折及对应阴影，原 A 边框的厚度、双线、切角、层次、高光阴影和磨损全部保留，不借此调整边框。此前扩大为整体平纸、削薄或压平边框的探索已废弃。

本轮未完成逐像素小图可读性验收、纹理编译或游戏内验证。单张样稿足以比较大图的笔触和材质，但不能视为最终运行时母版。

## 初轮选型时的比较依据

初轮比较优先看主图空间、三类轮廓和小图简化后的观感，再看收藏册装饰。以下是当时三种方向的取舍记录；当前已选择 A。

- 希望尽量贴近游戏手绘纸牌气质：优先 A。
- 希望收藏册更有古籍装帧和收藏品的精致感：优先 B。
- 希望整体更加神秘、装饰感更鲜明：优先 C，同时需要收敛内侧荆棘。

当前制作范围：只去除 A 的两处内侧卷角并验收 → 按已选边框制作三主类高清母版与各用途资源 → 角标组合与实机检查。收藏册、物品栏与地面版本只删除同类卷角，不另设计边框。最终需求以设计规范及用户后续选择为准。
