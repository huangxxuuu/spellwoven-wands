## 必须表达的结构

序列按实际顶牌到最下面一张读取：

- **RRR**：全矩形对照，三张纸的同形边缘自然连续，不增加缺角凹槽。
- **RHR**：中间六角牌收窄的位置没有纸。上层矩形角部悬出，下层矩形仍在下面承托，中间形成有深度的暗凹位。不能用连续浅色侧边把空位填满。
- **RRH**：最下层六角牌的缺角位置没有矩形底座；上方矩形角部悬出，可见下方地面或接地阴影。不能只保留一个中心尖角而把其余底边仍画成长矩形。
- **RHH**：下面两层都按六角形收窄，退进的空间与双层前尖同时存在，不能保留两条假矩形侧墙。

N 顶牌在这些前侧区域按相同原则处理。H 顶牌则继续使用它自身真实轮廓；已有的矩形露角不因此删除。

## 表现约束

- 纸牌依然平放、同向、基本对齐；有纸的位置自然接触，不拉开整张纸之间的空气层。
- 缺角区域表现为上层悬边、内凹阴影、退进的真实六角侧壁或下层受遮蔽的纸面。侧壁是否可见由视角和遮挡决定，不能强行把被盖住的线画到顶牌上。
- 有下层矩形承托的凹槽不应画成穿透整堆的透明孔；只有整个下方都无卡牌时才露出背景。
- 六角形前尖是同一张完整六角纸的一部分，不是贴在矩形外侧的装饰三角。
- 边框颜色、框宽和主图留白沿用 v3；不加破损、卷边或新的法术图案。

几何参考可适度强调层厚以说明空间，但正式游戏图仍需回到薄纸尺度并验证缩小后的辨识度。
