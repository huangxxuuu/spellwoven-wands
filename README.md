# 织法之杖 · Spellwoven Wands

你的下一发法术，由你亲手编织。收集随机法杖，自由排列法术卡，组合追踪、碰撞与定时载荷，把熟悉的武器变成魔法，和朋友一起寻找新的搭配。灵感来自《Noita》，面向《饥荒联机版》，支持中文与 English。

**[在线资料站](https://huangxxuuu.github.io/spellwoven-wands/) · [English guide](https://huangxxuuu.github.io/spellwoven-wands/en/) · [问题反馈](https://github.com/huangxxuuu/spellwoven-wands/issues)**

Collect randomized wands and arrange spell cards to create your own attacks in Don't Starve Together. Combine homing, impact and timed payloads, turn familiar weapons into spells, and experiment with friends. Inspired by Noita. Chinese and English are supported.

## 源码与网站

本仓库同时维护 Mod 和资料站。`mod/` 可复制到游戏的 `mods/nw_weave_dev/` 中使用；房主在世界设置中启用，参与玩家也需安装。更新后重启游戏与世界。

| 目录 | 内容 |
| --- | --- |
| `mod/` | 可安装的 Mod：Lua 代码、贴图和动画 |
| `site/` | 资料站页面、翻译与图鉴生成脚本；`site/dist/` 是页面源文件和本地预览 |
| `assets_src/` | 美术源文件与构建输入 |
| `tests/`、`tools/` | Lua 回归测试、资源构建和安装工具 |
| `docs/` | 参数说明、测试步骤与开发记录；历史记录以文内版本为准 |

推送到 GitHub 的 `main` 分支后，GitHub Actions 会运行规则测试、从 Mod 数据生成中英文图鉴。网站只在公开仓库中明确手动触发 `deploy_public=true` 时部署；普通推送和 Pull Request 不部署。`site/public/` 是生成的发布目录，不需要提交；网站不会公开游戏存档或测试日志。

本地构建资料站（Python 3.12）：

```sh
python -m pip install -r tools/requirements-dev.txt
python tools/run_tests.py
python site/build_catalog.py --pages
python tools/check_site_links.py --directory site/public
python -m http.server 8765 --directory site/public
```

资料站构建和纯 Lua 测试不需要安装游戏。重新编译游戏贴图／动画需要 Windows 下的 Don't Starve Mod Tools；工具脚本中的游戏路径应按本机安装位置调整。已编译资源随 `mod/` 提供。

## 版本发布

统一入口为 `release.ps1`（或 `python tools/release.py`）。默认只打印计划；默认发布受众是私有，Steam 保留当前可见性，资料站作为私有 Release 的 ZIP 附件保存。脚本不会自动公开 GitHub 仓库。

```powershell
# 只看计划
.\release.ps1 --version 0.25.6
# 更新版本、检查并冻结文件，不上传
.\release.ps1 --mode prepare --version 0.25.6
# 发布冻结版本，首次 Steam 登录可能需要密码/验证码
.\release.ps1 --mode publish --resume 0.25.6 --steamcmd "D:\Tools\SteamCMD\steamcmd.exe" --steam-user YOUR_LOGIN
```

提交发生在独立发布 checkout，原工作区不自动提交。发布包含 Git 提交与标签、GitHub Release 附件、Steam 更新及资料站；记录在 `dist/releases/<版本>/state.json`，失败后用 `--resume` 继续。公开发布需要明确使用 `--audience public`，工坊公开还需要 `--steam-visibility public`。完整依赖、说明文件、失败恢复和首次公开步骤见 [发布流程](docs/发布流程.txt)，目标配置见 [release_config.json](tools/release_config.json)。

## 本地开发与测试说明

本地安装：运行 `.\.venv\Scripts\python.exe tools/install_mod.py`，将当前 `mod/` 同步到游戏的 `mods/nw_weave_dev` 并逐文件校验。专项冒烟测试只更新各自的测试目录，不能代替这一步。安装后完全退出并重开游戏和世界，才能刷新脚本、贴图及语言设置。开启服务器「开发者选项」后，在远程控制台输入 `nw_testscene()`；帮助、生成结果及失败原因均用 `print` 逐行打印，并回传给执行命令的客户端。

## 中英文本地化

模组设置提供「自动 / 中文 / English」，默认自动。自动读取本机 DST 语言：简繁中文环境显示中文，其他语言显示英文；通过原版 `GetModConfigData("language", true)` 读取本地选择，进入世界时发送显示偏好供检查对白使用。每位玩家可独立选择，更改后重新进入世界。卡牌、默认杖名、面板、操作按钮、制作分类及分类文字贴图均支持两种语言；羽毛笔自定义名字不翻译，旧存档默认名字可跨语言显示。

资料站支持浏览器语言自动选择与手动切换，选择保存在本机；中文页面位于 `site/dist/`，英文页面位于 `site/dist/en/`。英文图鉴与游戏共用 `mod/scripts/nw/locales/en.lua` 的卡名和效果。工坊英文介绍见 [Steam创意工坊介绍.en.txt](docs/Steam创意工坊介绍.en.txt)，中文原文继续保留。默认语言正文由发布脚本上传；Steam 独立英文介绍需在工坊页面维护。

维护翻译时保留所有 `%g`、`%d` 等格式参数。新增游戏文本用 `require("nw/locale").t` 包装，并补充 `locales/en.lua`；卡名变化后运行 `tools/build_localized_names.py`。分类图标用 `tools/build_crafting_sections.py` 生成中英文两套图集。网页正文翻译在 `site/page_translations.en.json`，运行 `site/build_catalog.py` 同时更新两种语言。`tools/check_localization.py` 检查缺词、格式参数、游戏数值一致性与网站双语数据。

## 当前实现

新增法术测试拳击袋：外观、装备和受击动作沿用原版，头顶火花作为标记。相邻伤害间隔不足 1 秒时累计总伤害，达到 1 秒则下一次重新计数；超过 9999 也显示完整整数。科学机器旁用 3 草、1 木板制作。每位玩家首次在 Boss 胜利时位于其 12 单位内，会额外掉落一张碰撞卡：5% 为碰撞触发修饰，95% 等概率抽六种基础弹的碰撞变体；不要求尾刀，不占普通掉卡名额，记录随玩家存档及换角色保留。测试生成命令：`c_spawn("nw_spell_punchingbag")`。首次奖励组件为 `nw_firstboss`，采用现有 Boss 最终胜利判定，阶段切换与重复事件不发奖。更新前的历史击杀不追溯。

检查法术卡和法杖时只朗读名称，卡牌悬停保留基础属性栏和简述，资料站仅将详细机制说明折叠到「详细数据」。用羽毛笔右键背包或地上的法杖可改名，最多 32 字；真正改名消耗一支，取消、空白或同名不消耗，名字随原版命名组件同步和保存。开启开发者选项后，`nw_testscene()` 列出 17 组验收场景；`nw_testscene("all")` 生成 23 个预装道具箱、17 块步骤木牌和 3 座工作站，也可按组生成。双人测试用 `nw_testscene("duo")`：5 组场景、10 个 A/B 专用道具箱、5 块说明木牌和奥术台，包含改名交接、载荷归属/PvP、弹道风压、离线/幽灵/跨分片，以及任一玩家活跃区与休眠清理；指南逐项列出 A/B 操作和预期，交换角色复测。`nw_testcleanup(20)` / `nw_testcleanup(1)` 准备休眠清理门槛测试。具体步骤见[当前验收清单](docs/11_法术卡测试指南.md#当前验收清单与成套测试箱)。

移动规则统一：普通弹、移动晶体、载荷卵与星体共用弹道和碰撞处理。加速卡在同组速度倍率之外每张增加 2 单位/秒初速度；普通追踪（范围 8、推进 36、阻尼 0.72）与短距离追踪（范围 3、推进 72、阻尼 1.44）可推动零初速实体，持续同向追踪时速度趋近 50 单位/秒；新增转向敌人（范围 8、180°/秒），仅改变方向。永久实体基础阻力使无外力速度每 4 秒减半，低于 0.1 时停下；追踪等持续推进可抵消阻力，有限寿命星体不额外施加此阻力。移动场地实体碰撞后保留并停下，穿透、反弹、穿墙仍有效。风压弹只推动载荷卵，沿命中方向增加其自身弹速一半的速度，不触发载荷，也不能推动两种晶体。速度和弹道状态随存档保存。目标选择只作用于当前施法分组，载荷需要另放选择卡。

所有性能限制与自动清理均默认关闭，载荷分支数量不设额外限制。可选的「永久移动实体自动清理」按分片统计有移动或追踪能力的近感晶雷、休眠晶体与载荷卵（主人离线而暂停的也计入），不计静止机关或有寿命的星体。每秒检查一次；总数超过 20 时，清除本轮所有连续 16 分钟处于原版休眠区域的实体，不会为了降到 20 而删除近期出现过的实体。按原版活跃／休眠区域判定，进入活跃区域重置计时，不使用固定距离；数量和计时独立，即使总数不超过 20 也持续累计，超过 20 才执行清理；累计最多 20 分钟，达到后停止增长，重置后重新累计；计时随存档保存，服务器关闭时间不累计；清理不引爆、不释放载荷。

## 独立专服自检

```powershell
.\.venv\Scripts\python.exe tools/smoke_server.py --seconds 50
```

默认使用游戏目录内与当前安装版本一致的专服程序，将 mod/ 复制到该游戏的 mods/nw_weave_dev。脚本只覆盖带本工作区所有权标记的测试目录，不改变正常存档的启用列表。测试存档在本工作区 test_worlds/nw_smoke_版本号/Cluster_1 中，从合法 LAN 范围 10998–11018 自动选择空闲端口，使用离线模式。结果写入 test_reports/server_smoke.log，随后通过 c_shutdown 请求退出；超时仅终止本脚本启动的进程。

development_smoke 配置默认关闭，仅独立自检启用。自检成功证明服务端加载和样本战斗／数据路径，不证明图形客户端表现或完整首版完成。

边界专项使用 `.\.venv\Scripts\python.exe tools/smoke_server.py --bounds --seconds 90`，安装到独立的 `nw_weave_bounds_test` 测试目录，使用独立存档并输出 `test_reports/server_smoke_bounds.log`。已验证真实地图的 5 单位缓冲、天然屏障规则、移动晶体／载荷卵／星体清理、越界旧存档实体、超过 30 单位的弹体，以及清理时不补发载荷、正确释放额度和空闲任务。天然墙规则在地表测试世界切换原版屏障判定进行验证，未单独生成洞穴世界。
